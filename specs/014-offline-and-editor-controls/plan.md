# 离线状态、用户分页和纯净编辑实现计划

**Spec**: [spec.md](spec.md)
**Date**: 2026-11-24

共享 WebSocket 在持有者生命周期内订阅客户端网络事件。收到离线事件后停止退避定时器、关闭旧连接并立即发布断开，恢复后重建连接。复用现有文档加入、重放及确认流程。

生产 Web 工作台确认已登录且后端可用后，调用现有应用壳安装入口。工作台和离线文档页面共用一次安装请求。失败后可在恢复连接或通过离线文档页重试。在线导航与新构建安装复用现有 Service Worker，按其正常生命周期交接。

管理后台用户列表以独立状态表示追加分页，共用当前查询的取消信号，保证已有行在请求期间继续显示。

宿主编辑模式控制光标显示。Slate 由宿主绘制，Markdown 通过现有 handle 的显示和清除方法控制，Sheet、Canvas 和 Slides 通过已发布包的选区或成员参数控制。保持编辑实例、正文状态和发布选区的生命周期。

用隔离 SQLite、生产构建和 Chrome 验证。应用壳升级使用发布基线及当前构建。生成证据写入 `artifacts/verification/`。

发布使用合并到 `main` 的同一源码提交。推送 `v0.2.43` 触发 GitHub Release 和桌面安装包工作流，从该标签启动 Docker Hub 镜像工作流。核对版本标签、镜像清单和 Release 附件的校验值。
