# 离线状态、用户分页和纯净编辑

**Level**: full
**Status**: verified
**Created**: 2026-11-24
**Decision**: 0.2.42 的文档宿主依赖 WebSocket 关闭来感知断开，Web 应用壳默认需要手动准备。用户要求跟随断网更新状态，在线自动准备离线文件，保留用户分页的位置，并增加隐藏他人光标的编辑模式。实时协作生命周期和应用壳发布行为按 full 级别记录。

## Scope

工作台在浏览器和桌面内置前端使用同一个网络状态与文档协作入口。生产浏览器工作台在线自动准备离线应用壳。管理后台用户列表追加分页结果。富文本、Markdown、表格、画板和演示文稿支持纯净编辑。

2026-11-24 用户确认发布这些改动。0.2.43 发布包括 GitHub 源码与 Release、Docker Hub amd64/arm64 镜像和 Windows/macOS 桌面安装包。

## Acceptance

- **AC-001**: 已打开且可离线编辑的文档，在客户端收到断网事件时立即显示离线提示。重新加入协作后恢复在线状态，待提交修改保留至服务端确认。共享连接在离线期间暂停重试。
- **AC-002**: 在支持 Service Worker 的生产站点登录后，自动准备当前构建的静态文件。从正在使用上版缓存的同源站点重新在线打开页面时加载新版入口及 JS。新版应用壳安装成功并交接后，服务不可达时可继续打开。
- **AC-003**: 管理后台点击「加载更多用户」时保留现有行和滚动位置。新结果接在末尾，查询改变后旧请求无法追加到新列表。
- **AC-004**: 编辑权限允许时，「纯净编辑」紧随「编辑」。纯净编辑隐藏当前视图中的其他会话光标、选区及其姓名标签，编辑、保存、实时同步及对外光标发布照常运行。切回编辑恢复显示。纯净编辑沿用现有会话内模式切换，只有阅读权限的账号继续进入阅读模式。
- **AC-005**: GitHub `v0.2.43`、Docker Hub `smartdoca/doca:0.2.43` 和 `latest`、Release 附件均从同一通过检查的提交发布。验证镜像架构、源码版本和附件校验值。
