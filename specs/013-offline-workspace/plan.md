# 本地离线工作台实现计划

**Spec**: [spec.md](spec.md)
**Date**: 2026-11-24

## 工作台与文档

保留实时校验，在 Web 工作台增加已缓存文档的入口。服务不可达时从本地启动信息恢复账号和目录。直接地址复用同一文档路由和编辑器。目录根据本地正文副本和已知权限展示可打开的条目。

已通过在线启动校验的账号写入 `doca.offline-session.v1`，每次账号或会话重建使用新的本地标识。`doca-offline-catalog-v1` IndexedDB 按账号和文档存储新版在线读取后的展示记录。只列出当前会话且存在对应格式正文副本的文档。管理权限的变化由现有在线校验确定。会话失效隐藏旧记录，明确资源拒绝使晚到的旧成功响应无法恢复该条目。

离线首页用「最近编辑」列出可用正文副本，明确访问「离线文档」时仍可下载静态前端。已注册的目标通过原文档路由打开，尽早异步读取本地缓存，同时请求服务端当前详情。存量显示键保留供原客户端使用。

五种宿主编辑器根据实际就绪状态、编辑权限和实时连接展示离线编辑提示。编辑、权限校验、持久化和重连继续经由同一协作会话。

## 静态资源

桌面复用现有内置前端和稳定的本地地址。浏览器将生产构建所需的静态资源保存到本地，让同源页面可在后端不可达时冷启动。账号接口、插件接口、附件和 WebSocket 通过原有网络路径访问。

## 持久化与验证

用生产 Web 构建、隔离 SQLite 账号和文档验证重新启动、超过 12 篇、旧条目仅在线重开才收录、账号隔离、授权拒绝和离线编辑同步。报告和截图写入 `artifacts/verification/offline-workspace/`。

## 发布

使用同一 GitHub PR 合并提交。按既有工作流发布 `v0.2.42` GitHub Release、`smartdoca/doca:0.2.42` 与 `latest`、通用 macOS 和 x64 Windows 0.2.42 桌面附件。核对远端摘要、源码标签和附件校验值。
