# 工作台冷启动与桌面后台请求

**Level**: standard
**Status**: implemented
**Created**: 2026-11-23
**Decision**: 登录页和工作台此前共用初始依赖，冷启动还等待所有 Web 插件完成加载。桌面后台标签的独立页面重复发送账号级轮询请求。将这些开销移出关键路径，并在 PR 阶段检查应用与桌面构建。

## Scope

基线为 Doca 0.2.39。调整宿主 Web 启动、桌面标签切换与构建检查。沿用登录、资源访问、插件注册与版本校验、桌面代理协议和持久格式。桌面代理端口冲突和存量 origin 数据处理另行决定。

## Acceptance

- **AC-001**: 常规未登录入口加载现有登录表单，工作台与插件界面按需加载。登录后进入服务器配置的默认首页。特殊链接沿用工作台入口。
- **AC-002**: 插件资源等待或失败期间，核心工作台可显示；直接打开插件路径时，在插件加载期间显示进度，并在注册后显示页面，保留授权和失败行为。
- **AC-003**: 桌面后台标签暂停导航、通知和在线心跳的周期请求，激活后刷新；文档协作、保存与编辑继续运行。
- **AC-004**: 代码 PR 执行类型检查、SQLite 冒烟和 Web 构建；桌面相关 PR 执行锁定的 Rust 测试。桌面 Rust 锁文件与当前版本一致。

## Design

常规入口通过共享 bootstrap 判断是否加载工作台，复用账号表单、语言设置、首页选择和会话规则。特殊路由直接加载工作台。WorkspaceApp 从已验证的 bootstrap 启动后台插件发现。桌面 shell 向单个 iframe 通知可见性变化，仅宿主账号级轮询消费状态。CI 复用现有构建命令和隔离测试。

## Tasks

- [x] T001 拆分登录入口并验证登录、默认首页与冷启动资源体积（AC-001）。
- [x] T002 将插件发现移出工作台渲染关键路径，验证直达路由和失败（AC-002）。
- [x] T003 暂停后台标签的账号级轮询，验证切换与恢复（AC-003）。
- [x] T004 同步锁文件并增加代码与桌面 PR 检查（AC-004）。

## Validation

**Result**: partial

- **AC-001** 本地 Chromium 使用生产 Web 构建和隔离 SQLite。常规登录从 40 个 JS 和 6 个 CSS 请求降至 12 个 JS 和 3 个 CSS，压缩体积从约 578 KB 降至 206 KB。通过表单登录后按导航配置进入用户组首页，同一浏览器的另一个登录页也能刷新会话。
- **AC-002** 模拟插件资源延迟约 2 秒并失败，首页先显示。Web 插件直达路由和移动 Web 插件路由在发现期间显示加载状态，成功后显示合成插件页面；资源失败时显示不可用状态。
- **AC-003** 在 Chromium 中运行真实桌面标签壳与 Web 前端，私有桌面接口使用桩。三个已打开标签模拟运行 62 秒，两个隐藏标签的导航、通知和在线心跳请求均为零，重新选中后立即发出三类请求。原生 WebView 未运行此浏览器场景。
- **AC-004** 代码 PR 和桌面 PR 工作流通过本地 YAML 解析。TypeScript、Web、浏览器扩展与画布构建通过，SQLite 冒烟 58 项通过。扩展回归 78 项通过，依赖 Redis 的 1 项跳过。macOS 锁定 Rust 测试 27 项通过。Windows runner 和远端 PR 工作流待执行。
- 本地运行记录位于 `artifacts/verification/workspace-startup-performance/`。
