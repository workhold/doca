# 0.2.33 发布计划

**Spec**: [spec.md](spec.md)

1. 以最新 main 创建隔离工作区，按明确文件清单导入本会话改动并审阅差异。AC-001。
2. 统一版本、Compose、双语发行说明与入口；保留 004 的既有本地验收，新增本次发行记录。AC-002。
3. 复用正式依赖和固定 PDF 运行时，运行类型、完整测试、生产构建、SDK/部署打包及 SDD/文档检查。PR CI 并行验证 PostgreSQL 17/18、文档和 SDD。AC-003。
4. 通过 PR 合入；将发布分支快进至接受的合并提交，从该固定分支运行既有双架构原生镜像构建/验收/发布 workflow。临时 Docker Hub secrets 只通过内存/标准输入传递，完成后删除并复核。AC-004。
5. 镜像验收通过后，从同一提交创建不可变 tag，等待 GitHub 附件发布并独立下载核对。通过后续 PR 记录回执，不移动已发布 tag。AC-005。

原始证据放在 `artifacts/verification/release-0.2.33/`。已有 0.2.32 制品保持不变；本轮不执行生产升级、数据转换或回滚操作。
