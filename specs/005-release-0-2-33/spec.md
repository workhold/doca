# Doca 0.2.33 提及样式发布

**Level**: full
**Status**: verified
**Created**: 2026-11-03
**Decision**: 用户明确要求“发dockerhub和github”，发布本会话已完成的文档与表格提及样式，使用正式 Sheet 0.2.17。

## Scope

从已发布 0.2.32 的最新 main 创建隔离候选，只纳入本会话的富文本/在线文档用户链接样式、当前用户高亮、胶囊圆角与垂直留白，以及 Sheet 0.2.17 身份视图 API 和宿主三个挂载入口。原工作区的 AI、管理页、文件页等其他未提交工作保持原样，不纳入此次发行。

## Acceptance

- **AC-001**: 候选仅包含本会话改动，正式 Sheet 0.2.17 的源码、注册表摘要和安装文件可追溯；原始截图、日志、凭据和用户数据不提交。
- **AC-002**: 版本、Compose、双语发行说明和文档入口统一为 0.2.33，说明完整胶囊圆角、蓝底白字及去下划线的范围。
- **AC-003**: 类型、完整回归、生产构建、SDK/部署打包、SDD/文档和 PR CI 检查完成，保留实际结果与限制。
- **AC-004**: 原生 Linux amd64/arm64 镜像分别通过既有验收后发布，固定版本与 latest 的远端索引和版本/源码标签一致。
- **AC-005**: 同一发行提交的不可变 v0.2.33 tag、GitHub Release 和七个附件发布成功，附件下载、校验和及部署/Web/SDK 内容核对通过，并记录审阅回执。

## Architecture and compatibility

本轮为 full：包含已完成的表格公共视图 API 接入，并执行正式发布边界。功能验收见 [004](../004-sheet-self-mentions/spec.md)，当前契约见[编辑器集成](../../docs/editor-integration.md)。

没有新增或改造兼容行为。Sheet 仍使用原生用户节点与 schema 6；model/Yjs/XLSX/preferences 八个 JS 入口与 0.2.15 字节一致，显示身份和颜色不写入内容。没有数据库、协议、历史读取、转换、迁移、默认字段回填或自动适配变化。插件 SDK 仍为 0.2.0。本轮仅发布制品，不操作运行中的用户部署或数据。
