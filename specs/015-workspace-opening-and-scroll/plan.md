# 实现计划

**Spec**: [文档打开状态与工作台滚动](spec.md)
**Date**: 2026-11-25

## Technical context

基线为 Doca 0.2.43，源码提交 `ba92e18`。富文本和 Markdown 分别使用宿主协作适配，表格、画板和演示文稿共用 `useSurfaceSync`。五个入口共用 `OfflineEditingNotice` 和 `Realtime`。工作台已为文档表格设计单一滚动区域和停靠筛选。文档和知识库注册的路由标记将页面渲染交给宿主。

## Decisions and boundaries

- 共用传输记录已经确认的断开。提示与当前文档同步状态组合，在断线重连期间保留，等文档重新加入并同步完成后清除。
- 由宿主渲染的文档和知识库选择工作台滚动区域。知识库卡片随工作台内容滚动。离线目录独立占用视口高度并允许滚动。
- 窄窗口下分栏视图默认显示文件夹列表。选择文件时打开独占预览，关闭预览后回到目录。
- 协作消息、权限校验、持久队列和 ACK 沿用现有路径。验证使用隔离账号和合成文档。
- 同步宿主、Compose 和桌面版本。通过 GitHub PR 检查后，用同一正式标签运行 GitHub Release、Docker Hub 双架构镜像和桌面安装包流程。
