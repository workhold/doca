# 文档打开状态与工作台滚动

**Level**: full
**Status**: verified
**Created**: 2026-11-25
**Decision**: 用户要求修复正常打开文档时闪现的离线提示，以及最近访问和知识库长列表无法滚动的问题，并补充检查知识册和文件夹。离线提示依赖协作连接生命周期，按 full 记录。用户组头像存储按用户确认暂缓。

## Scope

工作台从 0.2.43 的实现继续修正 Web 和桌面内置前端共用的五种编辑器离线提示、文档页最近访问、知识库卡片和离线文档目录滚动。检查并修复知识册、知识库文档树、个人文件夹和共享文件夹的内容溢出问题。

2026-11-26 用户确认发布 0.2.44，包括 GitHub 源码与 Release、Docker Hub 镜像和 macOS、Windows 桌面安装包。

## Acceptance

- **AC-001**: 在线打开或刷新文档时，首次连接或等待文档同步的过程保持离线提示隐藏。五种编辑器都适用，包括缓存副本先于同步显示的情况。
- **AC-002**: 有可编辑本地副本时，浏览器断网或协作连接实际失败会显示离线提示。恢复后等当前文档同步完成再隐藏。离线修改仍通过原持久队列等待服务端确认。
- **AC-003**: 文档页最近访问、知识库网格及离线文档目录在内容超过窗口高度时可以滚至末尾。工作台的顶部导航仍可用，文档页保留停靠的列表筛选。
- **AC-004**: 知识册列表、知识库文档树、共享文件夹列表和文件夹内容在视口内溢出时可滚到末尾。个人和共享文件夹的图标、列表和分栏视图可浏览长内容。窄窗口下分栏列表可见并可操作。
- **AC-005**: GitHub 的 `v0.2.44`、Docker Hub 的 `smartdoca/doca:0.2.44` 与 `latest`，以及 macOS 通用和 Windows x64 安装包都由通过检查的同一提交构建。核对公开镜像的两种架构、附件和校验值。
