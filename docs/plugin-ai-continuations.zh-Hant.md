# 後臺任務完成後續跑 AI

當前 SDK 原始碼 **0.2.0** 已匯出 `@smartdoca/plugin-sdk/ai` 中的 `aiContinuationsServiceToken`，服務名為 `ai.continuations.v2`。所有安裝的服務端外掛都可申請這項能力，知識冊使用同一個宿主機制。原始碼實現不代表已釋出 npm 或部署上線。

外掛宣告 `sdkRange: "^0.2.0"`，把 token 放入必需注入。缺少服務的宿主拒絕初始化，沒有透過舊 AI 服務契約的適配，也不會推斷歷史業務任務的等待關係。

外掛負責業務任務、當前許可權、穩定操作標識、持久結果和通知/outbox；資料使用公開的宿主管理儲存。宿主負責助手身份、等待檢查點、取消、模型續跑和技術限制。喚醒不構成業務授權，也不能替代人工審批。

1. 在 mount 註冊來源：`registerSource({id, pluginId, read})`。id 以 `<pluginId>.` 開頭，pluginId 必須等於安裝身份；解除安裝時自動清理註冊。
2. `read(context, {operationId})` 根據當前業務許可權讀取持久結果，返回版本 1 快照；無權或任務不可用時返回 null。上下文包含宿主重新讀取的身份與取消訊號，結果不能攜帶秘密。
3. 註冊的 AI 工具執行期間，用宿主提供的原始上下文呼叫 `wait(pluginId, context, {sourceId, operationId})`，返回 receipt。複製、偽造或工具結束後保留的上下文會被拒絕。業務任務先以穩定鍵冪等啟動，再登記等待。
4. 業務結果提交後呼叫 `wake(pluginId, {sourceId, operationId})`。重複通知只能領取一次助手檢查點。即使通知先於助手進入等待，宿主的定期核對和重啟恢復也會重新讀取持久來源。

快照欄位：`version:1`、`state`、`revision`、`summary`，以及可選 JSON `result`。state 為 `running`、`waiting_input`、`completed`、`failed`、`cancelled`。可處理的結果或人工決定變化時更新 revision；僅執行心跳不會喚醒模型。進入人工處理時續跑一次，助手可解釋待辦並繼續等待決定；結束後攜帶結果事實繼續原任務。結束的業務任務結果保持穩定，新執行使用新的 operationId。

宿主只儲存完整工具呼叫與回執。等待釋放模型執行槽，保留原任務和檢查點，不消耗異常恢復次數。登記、通知和真正續跑時重新鑑權；許可權撤回、使用者停用、來源解除安裝或新協議記錄無效會停止續跑，顯示錯誤並保留檢查點。取消助手等待不會自動取消外掛業務任務，後者由外掛提供操作。

技術限制：每輪最多 20 個等待，來源標識 120 字元，操作標識與 revision 200 字元，摘要 2000 字元，序列化快照 24000 字元，讀取期限 20 秒。按遊標分頁並限制並行讀取，慢來源不佔用普通模型執行槽。啟動核對在外掛組合完成後開始。

[英文文件](plugin-ai-continuations.zh-Hant.md) 提供公開 SDK 接入示例。示例中的 jobs 是外掛透過 `storage.sql.v1` 實現的業務倉庫，不是假定存在的 SDK 匯出；冪等啟動、許可權判斷及提交後通知均由外掛實現。

## 持久化與回退

只有顯式新登記的等待寫入嚴格版本 1 檢查點。資料庫任務狀態約束保持原樣，使用既有停放狀態；API 和介面展示 `awaiting_dependency`。沒有資料庫遷移、雙寫、舊記錄補欄位轉換或歷史任務自動喚醒。無效的新等待記錄拒絕續跑，保留診斷資料。

回退停止新登記和寫入，保留檢查點、業務結果與審計記錄。舊宿主不會續跑新協議；先取消仍在等待的助手任務，或停機並恢復匹配宿主，再回退。不會清空使用者資料。

知識冊的節點、來源、批次、模型輸出量和重試事實寫入現有審計儲存，不復制模型正文。執行詳情重新整理狀態、心跳、實際錯誤與最近 200 條記錄；不偽造歷史日誌，更早的已寫日誌仍保留在儲存中。
