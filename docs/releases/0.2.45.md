# Doca 0.2.45 · Library trackpad scrolling

[简体中文](0.2.45.zh-CN.md)

- The Libraries page scrolls up and down with a two-finger trackpad gesture while the pointer is over a library card.

The GitHub Release provides a universal macOS DMG, Windows x64 EXE and MSI installers, Web assets, deployment files, and the plugin SDK archive. The Docker Hub image `smartdoca/doca:0.2.45` supports Linux amd64 and arm64. [GitHub Release](https://github.com/workhold/doca/releases/tag/v0.2.45)

When upgrading, retain the existing database, file storage, configuration, and credential master key. [Deployment guide](../deployment.md)
