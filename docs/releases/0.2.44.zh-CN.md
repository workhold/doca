# Doca 0.2.44 · 文档打开与列表滚动

[English](0.2.44.md)

- 富文本、Markdown、表格、画板和演示文稿在正常打开及首次同步时隐藏离线提示。检测到连接中断后显示提示，当前文档重新同步完成后收起。
- 最近访问、知识库卡片和离线文档目录可滚到最后一项。最近访问列表滚动时，筛选停靠在顶部。
- 窄窗口下，个人和共享文件夹的分栏视图可浏览目录。关闭文件预览后回到原来的滚动位置。

GitHub Release 提供 macOS 通用 DMG、Windows x64 EXE 和 MSI 安装包，以及 Web 资源、部署文件和插件 SDK 压缩包。Docker Hub 镜像 `smartdoca/doca:0.2.44` 支持 Linux amd64 和 arm64。[GitHub Release](https://github.com/workhold/doca/releases/tag/v0.2.44)

升级时请保留现有数据库、文件存储、配置和原凭证主密钥。[部署说明](../deployment.zh-CN.md)
