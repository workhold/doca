# Doca 0.3.1 · 管理画面の翻訳とレイアウト

[English](0.3.1.md)

- 管理画面に組み込まれている 13 項目のメニュー名と読み上げ用のラベルが、選択した表示言語に切り替わります。
- AI 管理画面では、プロバイダーの説明、長い URL、モデル名、操作ボタンがカード内で折り返されます。画面幅が狭い場合は設定画面のヘッダーも折り返し、管理メニューは個別にスクロールできます。

## アップグレード

既存のプロジェクト名、ボリューム、データベース、非公開オブジェクト、認証情報のマスターキーを保持したまま、`smartdoca/doca:0.3.1` イメージに切り替えてください。デスクトップ版には macOS のユニバーサル DMG と Windows x64 の NSIS・MSI インストーラーを用意しています。[デプロイガイド](../deployment.ja.md) · [デスクトップ版ガイド](../desktop-client.ja.md)
