# Doca 0.2.33 — 统一用户提及样式

[English](0.2.33.md)

富文本、在线文档中的用户链接和在线表格，@ 当前登录用户时统一显示胶囊圆角的蓝底白字。用户提及去掉下划线，并平衡上下留白；普通链接保留原有样式，悬停提及时保持对应颜色。

正式表格包 Sheet 0.2.17 在网格、公式栏、单元格编辑态和只读预览中使用一致的原生提及样式。Doca 为正文、历史/回收站和模板入口传入当前用户身份。切换或清空身份只重绘视图，不向共享内容写入个人颜色或身份。

本次没有数据库、持久化格式、协同、历史读取或转换变化。表格仍为 schema 6，公开插件 SDK 仍为 0.2.0。既有安装要求见 [0.2.31 发行说明](0.2.31.zh-CN.md)。升级时保留原数据库、文件、持久卷、配置和凭证主密钥。

Docker Hub 目标为 Linux amd64/arm64 的 `smartdoca/doca:0.2.33` 和 `latest`。制品发布和附件下载验证不等同于运行中的部署已经升级。
