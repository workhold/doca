# Doca 0.3.0 · Ocho idiomas de interfaz

[English](0.3.0.md) · [简体中文](0.3.0.zh-CN.md) · [繁體中文](0.3.0.zh-Hant.md) · [日本語](0.3.0.ja.md) · [Français](0.3.0.fr.md) · [한국어](0.3.0.ko.md) · [Español](0.3.0.es.md) · [Русский](0.3.0.ru.md)

Doca está disponible en chino simplificado, inglés, chino tradicional, japonés, francés, coreano, español y ruso. Elige el idioma en la pantalla de inicio de sesión o en la configuración de tu cuenta. Los administradores pueden configurar el idioma predeterminado del sitio. Los menús, las barras de herramientas y los avisos de los cinco editores usan el idioma del espacio de trabajo.

El gestor de conexiones de escritorio y el asistente del navegador incluyen los nuevos idiomas. El README y la documentación del proyecto están disponibles en los ocho idiomas, con capturas de la interfaz en cada uno.

<a id="upgrade"></a>

## Actualización

Conserva el nombre del proyecto, los volúmenes, la base de datos, los objetos privados y la clave maestra de las credenciales. Antes de cambiar a la imagen `smartdoca/doca:0.3.0`, consulta la [guía de despliegue](../deployment.es.md) y las [preferencias de idioma](../i18n.es.md). Las preferencias de idioma usan la estructura de base de datos actual. Si vuelves a la versión 0.2.46, conserva los valores guardados de cuenta y sitio. Evita guardar cambios de idioma en esa versión para recuperar tu selección al volver a la 0.3.0.
