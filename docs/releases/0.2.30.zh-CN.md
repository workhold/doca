# Doca 0.2.30 — MCP 独立执行与分级 SDD

[English](0.2.30.md)

MCP 工具调用现在创建独立执行任务。权限、租约、取消、操作回执和实际模型用量与聊天工具共用，不创建对话或记忆线程。个人设置 → MCP → 执行记录支持查看状态、当前有权访问的关联资源、停止执行和清理关闭记录，保留已保存文档、文件和宿主审计/用量事实。

最新 DDL 将任务的聊天/模型关联及保留的 MCP 聊天引用改为可空，通过已批准的协调器加入空的 `ai_task_resources` 表。既有行原样保留，不转换；历史 MCP 对话从聊天入口排除，不续跑。兼容代际不变。

插件 SDK 源码为 **0.2.0**，服务为 `ai.v2` / `ai.continuations.v2`。任务始终以 `jobId` 标识，真实聊天才提供 `sessionId`。插件须按 `sdkRange: "^0.2.0"` 重新构建，宿主、Web、插件协调更新；旧范围和服务直接拒绝，不提供适配。升级前备份，不提供应用自动降级。

SQLite 和 PostgreSQL 17/18 验证包含实际发布版 0.2.29 的历史数据、行保留、重复/并发启动和结构审查拒绝，见[验证记录](../verification/mcp-execution-decoupling-2026-11-01.md)。发布成功后的远端验收另行记录；发布制品不等于部署运行中的实例。

仓库接入[分级 SDD](../sdd.zh-CN.md)，包含 full/standard/light 记录、模块索引、固定版本 Spec Kit 1.0.4 和 PR 追溯检查；此流程改动不改变运行时数据。

GitHub Release 提供 SDK 0.2.0 编译包与校验文件供插件重新构建，本次不向 npm 发布 SDK。Docker Hub 目标为原生 Linux amd64/arm64 的 `smartdoca/doca:0.2.30` 和 `latest`。浏览器扩展保持 0.2.11。
