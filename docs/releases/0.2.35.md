# Doca 0.2.35 — Behavior-equivalent code simplification

[中文](0.2.35.zh-CN.md)

This release folds in a round of behavior-equivalent internal simplification: the file manager's plain and column views share the existing sort and action button implementations; AI administration and file recognition settings reuse the model input controls and strategy checkboxes; the dashboard and pinned document list share the favorite/pin patch mapping; the three AI image-edit mask rasterization paths converge on one implementation. Filter scopes, ordering, single/multi-select behavior and accessibility labels keep their original behavior.

There are no interface, database-structure, persisted-format, permissions, public-API or collaboration-protocol changes. Editor packages remain unchanged, including Sheet 0.2.17. Existing upgrade requirements are unchanged; see [0.2.34](0.2.34.md) and the linked earlier requirements. Preserve existing databases, files, configuration and the original master key when upgrading.

Publication targets `smartdoca/doca:0.2.35` and `latest` for Linux amd64/arm64, plus GitHub Release `v0.2.35`. Publication checks and running deployments are separate; publishing artifacts does not upgrade existing instances.
