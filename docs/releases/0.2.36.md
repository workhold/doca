# Doca 0.2.36 — Spreadsheet corner styling

[中文](0.2.36.zh-CN.md)

This release installs `@smartdoca/sheet` 0.2.18. The spreadsheet's select-all control now has square edges in the Doca host, filling the top-left grid corner without the exposed background caused by the host's button radius. Its select-all action and accessible label are unchanged.

This is a visual package update. It does not change database structure, persisted document formats, permissions, public editor APIs or collaboration behavior. Existing upgrade requirements are unchanged; see [0.2.35](0.2.35.md) and the earlier requirements linked from it. Keep the existing database, files, configuration and original master key when upgrading.

Publication targets GitHub Release `v0.2.36` and `smartdoca/doca:0.2.36` plus `latest` for Linux amd64 and arm64. Publishing artifacts does not upgrade running installations.
