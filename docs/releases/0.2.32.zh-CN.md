# Doca 0.2.32 — 当前用户的 @ 提及高亮

[English](0.2.32.md)

@ 当前登录用户时，将蓝色背景、白色文字、圆角和内边距直接应用于可点击的用户标签。鼠标悬停和展开用户资料卡片时继续保持蓝底白字，其他用户的提及保持原有显示。

本次仅调整 CSS，复用既有当前用户 ID 判断；共享标签样式用于文档提及和评论，不改变表格画布原生绘制的提及。

不修改数据库、持久化格式、API、SDK 或协作行为，公开插件 SDK 仍为 0.2.0。既有安装要求见 [0.2.31 发行说明](0.2.31.zh-CN.md)。

Docker Hub 目标为 `smartdoca/doca:0.2.32` 与 `latest`，Linux amd64/arm64。制品发布与运行中部署分开验证。
