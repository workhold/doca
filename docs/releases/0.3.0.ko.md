# Doca 0.3.0 · 인터페이스 언어 8종

[English](0.3.0.md) · [简体中文](0.3.0.zh-CN.md) · [繁體中文](0.3.0.zh-Hant.md) · [日本語](0.3.0.ja.md) · [Français](0.3.0.fr.md) · [한국어](0.3.0.ko.md) · [Español](0.3.0.es.md) · [Русский](0.3.0.ru.md)

Doca는 이제 중국어 간체, 영어, 중국어 번체, 일본어, 프랑스어, 한국어, 스페인어, 러시아어를 지원합니다. 로그인 화면 또는 계정 설정에서 언어를 선택할 수 있습니다. 관리자는 사이트 기본 언어를 지정할 수 있습니다. 편집기 다섯 종류의 메뉴, 도구 모음, 안내 메시지는 작업 공간 언어를 따릅니다.

데스크톱 연결 관리자와 브라우저 도우미에 새 언어를 추가했습니다. 프로젝트 README와 문서는 여덟 가지 언어로 제공되며, 각 언어로 표시된 실제 화면을 담았습니다.

<a id="upgrade"></a>

## 업그레이드

기존 프로젝트 이름, 볼륨, 데이터베이스, 비공개 객체, 자격 증명 마스터 키를 유지하세요. `smartdoca/doca:0.3.0` 이미지로 전환하기 전에 [배포 가이드](../deployment.ko.md)와 [언어 설정 규약](../i18n.ko.md)을 확인하세요. 언어 설정은 기존 데이터베이스 구조를 사용합니다. 0.2.46으로 되돌릴 때도 저장된 계정 및 사이트 설정을 유지하세요. 0.3.0으로 복귀한 뒤 기존 선택을 복구할 수 있도록 이전 버전에서는 언어 설정 저장을 피하세요.
