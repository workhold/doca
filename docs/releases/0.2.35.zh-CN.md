# Doca 0.2.35 — 代码等价简化

[English](0.2.35.md)

本版本合并了一轮行为等价的内部简化：文件管理的普通列表与分栏视图共用原有排序和操作按钮实现；AI 管理与文件识别设置复用模型输入控件和策略复选框；首页与固定文档列表共用收藏、固定状态的补丁映射；AI 图像编辑的三处蒙版栅格化收敛为同一实现。过滤范围、排序、单选/多选和无障碍标签保持原行为。

没有界面行为、数据库结构、持久化格式、权限、公开 API 或协作协议变化。编辑器依赖版本不变，表格仍为 Sheet 0.2.17。既有升级要求不变，见 [0.2.34](0.2.34.zh-CN.md) 及其引用的前置要求；升级时保留数据库、文件、配置和原始主密钥。

发布目标为 Linux amd64/arm64 的 `smartdoca/doca:0.2.35`、`latest` 和 GitHub Release `v0.2.35`。制品发布验证与实际运行环境的部署分别记录，发布不会自动升级已有实例。
