# Doca 0.2.43 · 离线编辑与纯净模式

[English](0.2.43.md)

- 客户端检测到断网后，已打开文档立即切换到离线编辑。协作连接恢复后，本地修改自动同步。
- Web 工作台在联网登录后自动准备离线前端。在线打开或刷新时加载服务端当前构建，使用旧缓存的标签页都关闭后由新版离线缓存接管。
- 管理后台「加载更多用户」在原位置追加结果，保留滚动位置。
- 「编辑」下方新增「纯净编辑」。富文本、Markdown、表格、画板和演示文稿均可隐藏当前视图中的其他协作者光标和选区，编辑和同步照常运行。

[GitHub Release](https://github.com/workhold/doca/releases/tag/v0.2.43) 提供 macOS 和 Windows 安装包、Web 资源、部署文件及插件 SDK 包。Docker Hub 镜像 `smartdoca/doca:0.2.43` 面向 Linux amd64 和 arm64。

升级时保留现有数据库、文件存储、配置和原凭证主密钥。见[离线文档与恢复](../access-offline-events.md#离线文档入口)。
