# Doca 0.3.0 · 八種介面語言

[English](0.3.0.md) · [简体中文](0.3.0.zh-CN.md) · [繁體中文](0.3.0.zh-Hant.md) · [日本語](0.3.0.ja.md) · [Français](0.3.0.fr.md) · [한국어](0.3.0.ko.md) · [Español](0.3.0.es.md) · [Русский](0.3.0.ru.md)

Doca 現在支援簡體中文、英語、繁體中文、日語、法語、韓語、西班牙語和俄語。使用者可在登入頁面或帳號設定中選擇語言，管理員可以設定站台的預設語言。五種編輯器的選單、工具列與提示會跟隨工作區的語言。

桌面連線管理員與瀏覽器助手加入了新的語言選項。專案 README 和文件均提供八種語言，畫面擷取自各語言的實際介面。

<a id="upgrade"></a>

## 升級

請保留現有的專案名稱、儲存磁碟區、資料庫、私有物件與憑證主金鑰。改用 `smartdoca/doca:0.3.0` 映像檔前，請參閱[部署指南](../deployment.zh-Hant.md)與[語言偏好說明](../i18n.zh-Hant.md)。語言偏好沿用現有資料庫結構。降回 0.2.46 時，請保留已儲存的帳號與站台語言設定。回退期間請避免儲存語言設定，以便恢復 0.3.0 後使用原選擇。
