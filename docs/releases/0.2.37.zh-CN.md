# Doca 0.2.37 — 桌面客户端首发

[English](0.2.37.md)

本版首次公开发布 Windows 与 macOS 桌面客户端。桌面应用打包 Doca Web 前端，连接你部署的 Doca 服务：工作空间窗口支持独立标签页，多个后端可同时连接；登录在系统浏览器完成，桌面凭证保存在本机加密文件中。窗口、标签顺序和站内路由按后端分别保存，对应凭证仍有效时重启自动恢复。插件仍安装并运行在所选服务端，桌面端通过认证代理加载。当前安装包未做签名与公证：macOS 首次打开需右键 →「打开」，Windows 可能出现 SmartScreen 提示。桌面客户端要求本版服务端，见[桌面客户端说明](../desktop-client.zh-CN.md)。

桌面安装包当天已修复重发：macOS 连接管理器不再把「钥匙串无该条目」当作凭据库错误，首次添加的地址直接进入未登录状态并可正常发起浏览器登录。如在修复前下载，请重新获取附件。

服务端同步提供桌面回跳接口。桌面授权使用单独存储哈希、无时间期限的凭证；显式桌面退出、修改或重置密码、禁用账号和管理员撤销都会使其失效，重新启用账号不会恢复已撤销凭证。数据库在当前兼容代际新增空的 `desktop_auth_flows` 与 `desktop_sessions` 表；既有浏览器、移动端和浏览器助手登录不受影响。升级后的数据库回到旧版服务端时可能被拒绝；应保留完整数据库并恢复对应的新版服务端。

管理后台把上传限额移入独立的「上传限额」标签页，仍通过既有管理 API 编辑同一份版本化策略，文案说明单文件限额同时适用于 AI 附件与文件上传。AI 管理页不再保留 uploads 子标签。

在线文档第一行现在紧贴固定工具栏：评论面板关闭时，悬浮评论按钮不再占据纵向空间。本地工作空间的分享链接提示改为词条文案。

## 升级与恢复

既有部署升级前阅读 [0.2.36](0.2.36.zh-CN.md) 及其引用的前置要求，升级时保留现有数据库、文件、配置和原始主密钥。桌面相关两张表是已声明的结构新增，由启动对账自动应用；不转换、不回填、不删除任何已有数据，全新建库使用同一目标 DDL。本版桌面客户端连接不带桌面接口的旧服务端会被拒绝；安装桌面客户端不改变服务端。服务端回滚到旧版前，需要先在副本上移除两张桌面表——不要在运行中的数据库上原地降级。

## 发布

发布目标为 GitHub Release `v0.2.37`——包含 Web 资产、部署包、插件 SDK，以及 Windows 与 macOS 桌面安装包——和 Linux amd64/arm64 的 `smartdoca/doca:0.2.37` 与 `latest`。制品发布不会自动升级运行中的实例。
