# Doca 0.3.0 · 八种界面语言

[English](0.3.0.md) · **简体中文** · [繁體中文](0.3.0.zh-Hant.md) · [日本語](0.3.0.ja.md) · [Français](0.3.0.fr.md) · [한국어](0.3.0.ko.md) · [Español](0.3.0.es.md) · [Русский](0.3.0.ru.md)

Doca 现支持简体中文、英语、繁体中文、日语、法语、韩语、西班牙语和俄语。用户可在登录页或账号设置中选择语言，管理员可设置站点默认语言。五种编辑器的菜单、工具栏和提示随工作区语言切换。

桌面连接管理器和浏览器助手加入了新的语言选项。项目 README 和文档同步提供八种语言，各语言截图来自对应语言的实际界面。

## 升级

保留现有项目名、存储卷、数据库、私有对象和凭证主密钥。切换到 `smartdoca/doca:0.3.0` 镜像前，参阅[部署指南](../deployment.zh-CN.md)和[语言偏好说明](../i18n.zh-CN.md)。语言偏好沿用现有数据库结构。降回 0.2.46 时保留已保存的账号和站点设置。回退期间请避免保存语言设置，以便恢复 0.3.0 后继续使用原来的选择。

参见[编辑器版本](../editor-integration.zh-CN.md)和[验收记录](../../specs/018-add-interface-languages/validation.md)。
