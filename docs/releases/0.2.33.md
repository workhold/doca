# Doca 0.2.33 — Consistent user mention badges

[中文](0.2.33.zh-CN.md)

Mentions of the signed-in user use a capsule-shaped blue background and white text in rich text, online-document user links and online spreadsheets. User mentions omit underlines, with balanced vertical spacing; ordinary links retain their existing styling. Hovering a mention preserves its colors.

The official Sheet 0.2.17 renders native mentions consistently in the grid, formula bar, cell drafts and readonly previews. Doca supplies current-user identity in active documents, history/trash previews and templates. Switching or clearing identity only repaints the view; it does not write personal colors or identity into shared content.

There are no database, persisted-format, collaboration, historical-reader or conversion changes. Sheet remains schema 6 and the public plugin SDK remains 0.2.0. Existing installation requirements remain in the [0.2.31 release notes](0.2.31.md). Preserve existing databases, files, volumes, configuration and credential master keys when upgrading.

Docker Hub targets `smartdoca/doca:0.2.33` and `latest` for Linux amd64/arm64. Publication and downloaded attachments are verified separately from running deployments.
