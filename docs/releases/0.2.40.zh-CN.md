# Doca 0.2.40 — 桌面文件操作与工作台启动

[English](0.2.40.md)

## 桌面端与文件

- PDF 预览会按 WebView 选用的 PDF.js 构建加载对应的 worker。已在 WebKit 26.5 和 Chromium 中打开测试 PDF。较旧的 WebKit 测试环境仍会在提取 PDF 文本层时报错。
- 上传和解析状态更新时，文件列表保持可见。把本地文件拖到可写文件夹上，就能在上传确认框中核对目标。选中至少两个文件后，可以通过「下载 ZIP」一次保存。
- 在新标签页打开站外链接时，桌面端会调用系统浏览器。同一后端和账号通常会复用本地代理地址，重新启动后可读取该地址下保存的偏好和离线状态。如果端口被占用，本次启动可能改用另一个地址，显示该地址对应的本地数据。此前随机地址下的数据原样保留。

## 工作台启动

登录页加载更少的代码，主工作台可在 Web 插件加载期间打开。直达插件页面会显示加载状态。桌面后台标签暂停导航、通知和心跳请求，切回时刷新。文档编辑和保存继续运行。

## 下载与升级

[GitHub Release](https://github.com/workhold/doca/releases/tag/v0.2.40) 提供 macOS 与 Windows 安装包、Web 资源、部署文件和插件 SDK 归档。Docker Hub 镜像 `smartdoca/doca:0.2.40` 支持 Linux amd64 与 arm64。

本版沿用 [0.2.39](0.2.39.zh-CN.md) 的数据库结构和服务端格式。升级时保留原数据库、文件存储、配置和主密钥。
