# Doca 0.2.42 · 离线文档

[English](0.2.42.md)

- 后端不可达时，桌面版和事先下载前端的浏览器从首页**最近编辑**打开本地副本。网页版可在**账号菜单 → 离线文档**下载前端。
- 用本版联网打开且成功缓存正文的每篇文档都会收录。旧版打开过的文档需用本版联网打开一次。目录可按文档或文库名称搜索。
- 有编辑权限时会显示离线编辑提示。正文改动先保存在本机，文档打开时会重连并自动同步，已关闭的文档重开后继续同步。

[GitHub Release](https://github.com/workhold/doca/releases/tag/v0.2.42) 提供 macOS 和 Windows 桌面安装包、Web 资源及部署附件。Docker Hub 镜像 `smartdoca/doca:0.2.42` 面向 Linux amd64 和 arm64。

离线目录在客户端新增，服务端按普通版本升级。保留现有数据库、文件存储、配置和主密钥。见[离线文档说明](../access-offline-events.md#离线文档入口)。
