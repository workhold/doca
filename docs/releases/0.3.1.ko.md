# Doca 0.3.1 · 관리 화면 번역과 레이아웃

[English](0.3.1.md)

- 관리 화면의 기본 메뉴 13개와 접근성 레이블이 선택한 화면 언어로 표시됩니다.
- AI 관리 화면에서 공급업체 설명, 긴 주소, 모델 이름과 작업 버튼이 카드 안에서 줄바꿈됩니다. 화면 폭이 좁으면 설정 상단 영역도 줄바꿈되며 관리 메뉴는 별도로 스크롤할 수 있습니다.

## 업그레이드

기존 프로젝트 이름, 볼륨, 데이터베이스, 비공개 객체, 자격 증명 마스터 키를 유지한 상태에서 `smartdoca/doca:0.3.1` 이미지로 전환하세요. 데스크톱 앱은 macOS용 범용 DMG와 Windows x64용 NSIS 및 MSI 설치 프로그램으로 제공됩니다. [배포 가이드](../deployment.ko.md) · [데스크톱 앱 가이드](../desktop-client.ko.md)
