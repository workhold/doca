# Doca 0.3.0 · 8 言語のインターフェース

[English](0.3.0.md) · [简体中文](0.3.0.zh-CN.md) · [繁體中文](0.3.0.zh-Hant.md) · [日本語](0.3.0.ja.md) · [Français](0.3.0.fr.md) · [한국어](0.3.0.ko.md) · [Español](0.3.0.es.md) · [Русский](0.3.0.ru.md)

Doca は簡体字中国語、英語、繁体字中国語、日本語、フランス語、韓国語、スペイン語、ロシア語に対応しました。サインイン画面またはアカウント設定で表示言語を選べます。管理者はサイトの既定言語を設定できます。5 種類のエディターのメニュー、ツールバー、メッセージも、ワークスペースで選択した言語で表示されます。

デスクトップ版の接続マネージャーとブラウザーアシスタントにも新しい言語を追加しました。プロジェクトの README とドキュメントは 8 言語で公開し、それぞれの言語で撮影した画面を掲載しています。

<a id="upgrade"></a>

## アップグレード

既存のプロジェクト名、ボリューム、データベース、非公開オブジェクト、認証情報のマスターキーを保持してください。`smartdoca/doca:0.3.0` イメージに切り替える前に、[デプロイガイド](../deployment.ja.md)と[言語設定の仕様](../i18n.ja.md)をご確認ください。言語設定には従来のデータベース構造を使います。0.2.46 に戻す際も、保存済みのアカウントとサイトの設定は保持されます。0.3.0 に復帰したときに元の選択を再利用できるよう、旧版の運用中は言語設定の保存を避けてください。
