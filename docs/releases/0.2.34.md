# Doca 0.2.34 — English spreadsheet toolbar

[中文](0.2.34.zh-CN.md)

Online spreadsheet ribbon groups now size to their translated labels. When space is constrained, long labels stay within their buttons and show an ellipsis; the full action name remains available through the existing tooltip and accessible name. The native More menu continues to expose folded actions.

The host's AI and comment actions reserve their actual width instead of overflowing a fixed 130px area. The comment button follows the selected Chinese or English interface language, and the AI action keeps its color in both languages. Readonly mode retains its existing comment and AI actions.

This is a bounded layout and interface-copy correction. Editor packages remain unchanged, including Sheet 0.2.17. There are no database, stored-document, permissions, public API or collaboration-protocol changes. Knowledge books remain available. Existing upgrade requirements are unchanged; see [0.2.33](0.2.33.md) and the linked earlier requirements. Preserve existing databases, files, configuration and the original master key when upgrading.

Publication targets `smartdoca/doca:0.2.34` and `latest` for Linux amd64/arm64, plus GitHub Release `v0.2.34`. Publication checks and running deployments are separate; publishing artifacts does not upgrade existing instances.
