# Doca 0.2.34 — 英文表格工具栏

[English](0.2.34.md)

在线表格工具栏分组现在按翻译后的标签调整宽度。空间不足时，长标签限制在各自按钮内并显示省略号，悬停提示和无障碍名称仍保留完整操作名称。原生“更多”菜单继续提供折叠的功能。

宿主的 AI 和评论按钮区按实际宽度预留空间，避免超出原先的 130px 限制而盖住相邻按钮。评论按钮随中英文界面切换，AI 按钮在两种语言下保持相同配色。只读模式保留既有评论与 AI 入口。

本轮仅修正局部布局和界面文案。编辑器依赖版本不变，表格仍为 Sheet 0.2.17；没有数据库、文档存储、权限、公开 API 或协作协议变化。知识册保持可用。既有升级要求不变，见 [0.2.33](0.2.33.zh-CN.md) 及其引用的前置要求；升级时保留数据库、文件、配置和原始主密钥。

发布目标为 Linux amd64/arm64 的 `smartdoca/doca:0.2.34`、`latest` 和 GitHub Release `v0.2.34`。制品发布验证与实际运行环境的部署分别记录，发布不会自动升级已有实例。
