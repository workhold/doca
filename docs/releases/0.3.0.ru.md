# Doca 0.3.0 · Восемь языков интерфейса

[English](0.3.0.md) · [简体中文](0.3.0.zh-CN.md) · [繁體中文](0.3.0.zh-Hant.md) · [日本語](0.3.0.ja.md) · [Français](0.3.0.fr.md) · [한국어](0.3.0.ko.md) · [Español](0.3.0.es.md) · [Русский](0.3.0.ru.md)

В Doca теперь доступны упрощённый китайский, английский, традиционный китайский, японский, французский, корейский, испанский и русский языки. Язык можно выбрать на экране входа или в настройках аккаунта. Администратор может задать язык сайта по умолчанию. Меню, панели инструментов и подсказки всех пяти редакторов используют язык рабочего пространства.

Новые языки доступны в диспетчере подключений настольного клиента и в помощнике браузера. README и документация проекта опубликованы на всех восьми языках и содержат снимки соответствующих интерфейсов.

<a id="upgrade"></a>

## Обновление

Сохраните имя проекта, тома, базу данных, приватные объекты и главный ключ для учётных данных. Перед переходом на образ `smartdoca/doca:0.3.0` прочтите [руководство по развёртыванию](../deployment.ru.md) и раздел о [языковых настройках](../i18n.ru.md). Настройки языка сохраняются в существующей структуре базы данных. При откате до 0.2.46 сохраните значения для аккаунтов и сайта. Избегайте записи языковых настроек в старой версии, чтобы восстановить свой выбор при возврате на 0.3.0.
