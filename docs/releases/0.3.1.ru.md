# Doca 0.3.1 · Перевод и вёрстка панели администратора

[English](0.3.1.md)

- Все 13 встроенных пунктов меню администратора и их названия для программ чтения с экрана отображаются на выбранном языке.
- В разделе управления ИИ описания поставщиков, длинные адреса, названия моделей и кнопки переносятся внутри карточек. На узких экранах верхняя панель настроек может занимать несколько строк, а меню администратора прокручивается отдельно.

## Обновление

Перейдите на образ `smartdoca/doca:0.3.1`, сохранив имя проекта, тома, базу данных, закрытые объекты и мастер-ключ учётных данных. Для настольной версии доступны универсальный DMG для macOS и установщики NSIS и MSI для Windows x64.
