## 升级

保留原有项目名、存储卷、数据库、私有对象和凭证主密钥，切换到 `smartdoca/doca:0.3.1` 镜像。桌面端提供 macOS 通用 DMG 和 Windows x64 的 NSIS、MSI 安装包。[部署指南](../deployment.zh-CN.md) · [桌面端指南](../desktop-client.zh-CN.md)
