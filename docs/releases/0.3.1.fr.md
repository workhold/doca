# Doca 0.3.1 · Traductions et mise en page de l’administration

[English](0.3.1.md)

- Les 13 entrées intégrées du menu d’administration et leurs libellés d’accessibilité utilisent la langue sélectionnée.
- Dans la gestion de l’IA, les descriptions des fournisseurs, les adresses longues, les noms de modèles et les boutons s’adaptent à la largeur de leur carte. Sur les petits écrans, l’en-tête des paramètres passe sur plusieurs lignes et le menu d’administration défile séparément.

Passez à l’image `smartdoca/doca:0.3.1` en conservant le nom du projet, les volumes, la base de données, les objets privés et la clé maître qui protège les identifiants.
