# Doca 0.3.0 · Huit langues d’interface

[English](0.3.0.md) · [简体中文](0.3.0.zh-CN.md) · [繁體中文](0.3.0.zh-Hant.md) · [日本語](0.3.0.ja.md) · [Français](0.3.0.fr.md) · [한국어](0.3.0.ko.md) · [Español](0.3.0.es.md) · [Русский](0.3.0.ru.md)

Doca est désormais disponible en chinois simplifié, anglais, chinois traditionnel, japonais, français, coréen, espagnol et russe. Choisissez la langue sur l’écran de connexion ou dans les paramètres de compte. Les administrateurs peuvent définir la langue par défaut du site. Les menus, barres d’outils et messages des cinq éditeurs suivent la langue de l’espace de travail.

Le gestionnaire de connexions du client de bureau et l’assistant de navigateur proposent les nouvelles langues. Le fichier README et la documentation du projet sont disponibles dans les huit langues, avec des captures de l’interface dans chaque langue.

## Mise à niveau

Conservez le nom du projet, les volumes, la base de données, les objets privés et la clé principale de chiffrement des identifiants. Avant de passer à l’image `smartdoca/doca:0.3.0`, consultez le [guide de déploiement](../deployment.fr.md) et les [préférences linguistiques](../i18n.fr.md). Le stockage des préférences linguistiques conserve la structure de base de données existante. En revenant à la version 0.2.46, conservez les valeurs d’origine des comptes et du site. Évitez d’enregistrer des paramètres de langue sur cette version afin de retrouver vos choix au retour à la version 0.3.0.
