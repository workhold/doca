# Doca 0.2.43 · Offline editing and distraction-free mode

[简体中文](https://workhold.github.io/doca/#/zh-cn/releases/0.2.43)

- Open documents switch to offline editing as soon as the client detects a network outage. Local changes sync automatically when the collaboration connection returns.
- The Web workspace prepares its offline frontend automatically after sign-in. Online navigation and refresh load the current server build. The new offline cache takes over after the tabs using the previous cache close.
- **Load more users** appends results in place and keeps the current scroll position.
- Choose **Distraction-free editing** below **Edit** to hide other collaborators’ cursors and selections in the current document. Editing and synchronization continue across all five editors.

The [GitHub Release](https://github.com/workhold/doca/releases/tag/v0.2.43) provides macOS and Windows installers, Web assets, deployment files and the plugin SDK archive. The `smartdoca/doca:0.2.43` image targets Linux amd64 and arm64.

Keep the existing database, file storage, configuration and original credential master key when upgrading. See [offline documents and recovery](https://github.com/workhold/doca/blob/v0.2.43/docs/access-offline-events.md#离线文档入口).
