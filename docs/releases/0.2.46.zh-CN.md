# Doca 0.2.46 · 桌面端与登录页语言

[English](0.2.46.md)

- 桌面端的连接管理器和标签栏支持中文与英文。从工作空间打开管理器时跟随当前工作空间语言。独立启动时优先使用已保存的选择，其次使用系统首选语言列表中支持的语言，最后回退到英文。
- Web 登录页默认使用管理员设置的语言，可在登录卡片右上角即时切换。切换语言会保留已填写的内容和扫码登录状态。
- 宽屏登录页自动轮流演示文档编辑、表格公式计算和画布编辑。系统开启减少动态效果时显示静态画面。

GitHub Release 提供 macOS 通用 DMG、Windows x64 EXE 和 MSI 安装包，以及 Web 资源、部署文件和插件 SDK 压缩包。Docker Hub 镜像 `smartdoca/doca:0.2.46` 支持 Linux amd64 和 arm64。[GitHub Release](https://github.com/workhold/doca/releases/tag/v0.2.46)

升级时请保留现有数据库、文件存储、配置和原凭证主密钥。[部署说明](../deployment.zh-CN.md)
