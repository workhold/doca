# Doca 0.3.0 · Eight interface languages

[简体中文](https://workhold.github.io/doca/#/zh-cn/releases/0.3.0) · [繁體中文](https://workhold.github.io/doca/#/zh-hant/releases/0.3.0) · [日本語](https://workhold.github.io/doca/#/ja/releases/0.3.0) · [Français](https://workhold.github.io/doca/#/fr/releases/0.3.0) · [한국어](https://workhold.github.io/doca/#/ko/releases/0.3.0) · [Español](https://workhold.github.io/doca/#/es/releases/0.3.0) · [Русский](https://workhold.github.io/doca/#/ru/releases/0.3.0)

Doca now supports Simplified Chinese, English, Traditional Chinese, Japanese, French, Korean, Spanish, and Russian. Choose a language on the sign-in screen or in account settings. Administrators can set the site default. The five editors use the workspace language for menus, toolbars, and prompts.

The desktop connection manager and browser assistant include the new language choices. The project README and documentation are available in all eight languages, with screenshots captured from matching interface languages.

## Upgrade

Keep your project name, volumes, database, private objects, and credential master key when switching to the `smartdoca/doca:0.3.0` image. The language preferences use the existing database structure. A rollback to 0.2.46 keeps saved account and site values. Avoid saving language settings on the previous version to retain the new values for when you restore 0.3.0.
