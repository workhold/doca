# Doca 0.2.39 — 表格列宽调整防护

[English](0.2.39.md)

本版本将内嵌表格包升级到 `@smartdoca/sheet` 0.2.20，修复一个线上反馈的回归：当工作簿中存在一个退化富文本单元格（带有序列表 bullet、文档骨架产出空 pages）时，拖动列头边界无法调整该列宽度——线上反馈在第一列。表格引擎在应用宽度之前先测量锚点列，测量在该单元格上崩溃，整个命令静默失败：没有报错、没有提示、宽度不变。由于该单元格在界面上看起来是空的（公式栏不回显富文本），用户无法自行发现原因。表格包现在在唯一测量入口加防护：测量失败回退到调用方各自的默认值，列宽照常生效，首屏渲染不再被这类单元格破坏。同源崩溃破坏的其他列调宽记账也一并覆盖。

静默失败不再不可见：与本地表格命令关联的未处理拒绝按消息去重上报一次警告 toast，完整堆栈输出到控制台。表格包公开 API、声明、CSS 及 model/Yjs/XLSX/preferences 入口与 0.2.19 一致；详见[编辑器集成契约](../editor-integration.zh-CN.md#表格自动行高测量防护--2026-11-23)。

本次不包含数据库结构、持久化格式、公开 API 或权限变更；升级要求与 [0.2.38](0.2.38.zh-CN.md) 一致——升级时保留现有数据库、文件、配置和原始 master key。

发布目标为 GitHub Release `v0.2.39`（Web 资源、部署包、插件 SDK 及 Windows/macOS 桌面安装包）以及 Linux amd64/arm64 的 `smartdoca/doca:0.2.39` 与 `latest` 镜像。发布产物不会自动升级正在运行的实例。
