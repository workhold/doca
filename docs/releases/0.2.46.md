# Doca 0.2.46 · Desktop and sign-in languages

[简体中文](0.2.46.zh-CN.md)

- The desktop connection manager and tab controls now support Chinese and English. The manager follows the active workspace language when opened from a workspace. On a standalone launch, it uses a saved choice or the first supported system language, with English as the fallback.
- The Web sign-in card starts in the administrator's default language and offers a language dropdown. Switching languages keeps the current form entries and QR sign-in state.
- The wide sign-in page automatically cycles through document editing, spreadsheet recalculation, and canvas editing. It shows a static illustration when the system requests reduced motion.

The GitHub Release includes a universal macOS DMG, Windows x64 EXE and MSI installers, Web assets, deployment files, and the plugin SDK archive. The Docker Hub image `smartdoca/doca:0.2.46` supports Linux amd64 and arm64. [GitHub Release](https://github.com/workhold/doca/releases/tag/v0.2.46)

When upgrading, retain the existing database, file storage, configuration, and credential master key. [Deployment guide](../deployment.md)
