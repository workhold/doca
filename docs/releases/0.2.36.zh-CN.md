# Doca 0.2.36 — 表格左上角样式

[English](0.2.36.md)

本版接入 `@smartdoca/sheet` 0.2.18。表格左上角的全选按钮在 Doca 中保持方角，填满表格角块，不再因宿主按钮圆角露出底层背景。全选操作和无障碍标签不变。

这是一项组件视觉更新，不改变数据库结构、文档持久化格式、权限、编辑器公开 API 或协同处理。既有升级要求不变，见 [0.2.35](0.2.35.zh-CN.md) 及其引用的前置要求。升级时保留现有数据库、文件、配置和原始主密钥。

发布目标为 GitHub Release `v0.2.36`、Linux amd64/arm64 的 `smartdoca/doca:0.2.36` 与 `latest`。制品发布不会自动升级运行中的实例。
