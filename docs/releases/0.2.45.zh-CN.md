# Doca 0.2.45 · 知识库触控板滚动

[English](0.2.45.md)

- 修复知识库卡片区域无法响应触控板上下滑动的问题。光标停在卡片上时，双指滑动即可滚动列表。

GitHub Release 提供 macOS 通用 DMG、Windows x64 EXE 和 MSI 安装包，以及 Web 资源、部署文件和插件 SDK 压缩包。Docker Hub 镜像 `smartdoca/doca:0.2.45` 支持 Linux amd64 和 arm64。[GitHub Release](https://github.com/workhold/doca/releases/tag/v0.2.45)

升级时请保留现有数据库、文件存储、配置和原凭证主密钥。[部署说明](../deployment.zh-CN.md)
