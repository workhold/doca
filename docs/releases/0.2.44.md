# Doca 0.2.44 · Document startup and list scrolling

[简体中文](0.2.44.zh-CN.md)

- Rich text, Markdown, spreadsheets, canvases, and presentations keep the offline banner hidden during normal startup and initial sync. After a connection failure, the banner stays visible until the document finishes syncing again.
- Recent documents, library cards, and the offline document directory can scroll to the last item. The recent documents filters stay at the top while the list scrolls.
- In narrow windows, column view shows the contents of personal and shared folders. Closing a file preview returns to the same position in the folder.

The GitHub Release provides a universal macOS DMG, Windows x64 EXE and MSI installers, Web assets, deployment files, and the plugin SDK archive. The Docker Hub image `smartdoca/doca:0.2.44` supports Linux amd64 and arm64. [GitHub Release](https://github.com/workhold/doca/releases/tag/v0.2.44)

When upgrading, retain the existing database, file storage, configuration, and credential master key. [Deployment guide](../deployment.md)
