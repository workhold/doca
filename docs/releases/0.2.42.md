# Doca 0.2.42 · Offline documents

[简体中文](0.2.42.zh-CN.md)

- When the backend is unreachable, open local documents from **Recent edits** on home in the desktop app or a browser with the frontend downloaded. In a browser, use **Account menu → Offline documents** to download the frontend while connected.
- The directory lists each document opened online in this version whose body is available locally. Reopen earlier documents online once to add them. Search by document or library title.
- Editable replicas show the offline editing notice and save changes locally. Open documents sync when the connection returns. Closed documents resume sync when reopened.

[GitHub Release](https://github.com/workhold/doca/releases/tag/v0.2.42) provides macOS and Windows installers, Web assets and deployment files. The `smartdoca/doca:0.2.42` image targets Linux amd64 and arm64.

The directory is created on the client as part of the normal upgrade. Retain the existing database, file storage, configuration and credential master key. See [offline document setup and recovery](../access-offline-events.md#离线文档入口).
