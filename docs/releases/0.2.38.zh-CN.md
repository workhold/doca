# Doca 0.2.38 — 上传限制报错与桌面文档树拖拽

[English](0.2.38.md)

本版修复两个 0.2.37 的用户反馈问题。管理后台「上传限制」页面不再在打开时弹出「请求参数无效」报错：该页的用户选择器初始搜索携带空的 `q` 参数，管理端用户搜索接口按校验拒绝空值，失败请求被当成错误显示在表单下方。现在空搜索不再发送；按名称搜索仍正常过滤，限额编辑、全部不限快捷键、按用户覆盖和带版本校验的保存行为不变。

桌面客户端中，知识库文档树恢复拖拽调整位置。工作空间 webview 此前按 Tauri 默认启用了原生拖放处理器；在 macOS 上该处理器会接管视图的拖拽回调且不再转发给 WKWebView，页面收不到 dragover/drop，重排无法完成。工作空间 webview 现在禁用原生处理器——桌面壳不监听任何原生拖放事件——页面内 HTML5 拖拽恢复工作；副作用是从系统拖文件到工作空间页面会像浏览器一样作为普通 HTML5 drop 事件交给页面，不再被吞掉。连接管理器的拖拽行为保持不变。

本版同步更新桌面客户端的功能文档（指南、FAQ、功能表、README 截图）。不涉及数据库结构、持久化格式、公开 API 或权限变化；升级要求自 [0.2.37](0.2.37.zh-CN.md) 起不变——升级时保留现有数据库、文件、配置和原始主密钥。

发布目标为 GitHub Release `v0.2.38`——Web 资产、部署包、插件 SDK 与 Windows/macOS 桌面安装包——以及 Linux amd64/arm64 的 `smartdoca/doca:0.2.38` 与 `latest`。制品发布不会自动升级运行中的实例。
