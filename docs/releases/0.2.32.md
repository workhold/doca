# Doca 0.2.32 — Highlight mentions of the current user

[中文](0.2.32.zh-CN.md)

Mentions of the signed-in user apply the blue background, white text, rounded shape and padding directly to the clickable user label. The highlight remains blue and white while hovering and opening the user card. Mentions of other users retain their existing appearance.

This is a CSS-only refinement using the existing current-user identity check. The shared label styling applies to document mentions and comments. It does not change native canvas-drawn spreadsheet mentions.

There are no database, persisted-format, API, SDK or collaboration changes. The public plugin SDK remains 0.2.0. Existing installation requirements remain in the [0.2.31 release notes](0.2.31.md).

Docker Hub targets `smartdoca/doca:0.2.32` and `latest` for Linux amd64/arm64. Publication is verified separately from running deployments.
