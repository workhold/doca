# 네이티브 플러그인 캐시 및 첨부파일

[中文](plugin-native.zh-CN.md)

네이티브 플러그인 컨테이너에서 `host.ai.open` 사용 `assistant.open` 네이티브 개인 비서를 실행하기. 매개변수와 오류는 다음과 같습니다. [발사 계약](plugin-assistant.ko.md)프롬프트와 컨텍스트는 네비게이션 URL에서 제외되며, 계정 자격 정보는 WebView에서 제외됩니다. 프리필 요청은 현재 계정 및 일회성 실행 식별자에 의해 메모리에서 처리됩니다.

공용 타입은 여기서 나옵니다. `@smartdoca/plugin-sdk/native`, 노출됨 `PluginWebHost.native`이 속성은 웹에서는 null입니다. 앱 플러그인 컨테이너는 다음을 제공합니다:

- `storage.get(key)` / `set(key, value)` / `remove(key)` / `clear()`: 문자열 캐시, 각 값당 최대 200만 자, 각 플러그인당 2000만 자.
- `attachments.save({path,name,mime})` / `share(...)`: `path` 플러그인 API와 관련이 있습니다, 예를 들어 `/mailboxes/123/attachments/456?download=true`.

네이티브 호스트는 캐시 네임스페이스를 서버, 온라인 인증된 사용자 ID, 플러그인 ID에 바인딩합니다. 플러그인은 다른 식별자를 선택할 수 없습니다. 데이터는 앱의 영구 디렉터리에 저장되며 재시작에도 남아 있고, 계정 로그아웃하거나 계정을 삭제할 때 해당 서버에 대해 지워집니다. 쓰기 작업은 시리얼라이즈되며, 새로운 스냅샷이 이전 스냅샷을 대체하기 전에 완료됩니다. WebView는 임시적이고 격리된 상태로 유지되며, 로그인 쿠키는 영구 캐시 메커니즘이 아닙니다.

네이티브 호스트는 플러그인을 로드하기 전에 온라인에서 로그인된 ID를 확인합니다. 기존 플러그인 IndexedDB 코드는 자동으로 마이그레이션되거나 도입되지 않습니다; 플러그인은 명시적으로 사용합니다. `native.storage`완전히 오프라인 상태에서의 냉동 시작은 지원되지 않습니다. 앱을 제거하거나 시스템 저장소를 정리하면 캐시가 삭제될 수 있습니다.

첨부파일 다운로드는 내부 인증된 호스트를 통해 이루어집니다. 외부 원본으로의 리디렉션은 금지되며, 네이티브 세션 토큰은 WebView에 전혀 제공되지 않습니다. 첨부파일의 크기는 최대 32 MiB입니다. 임시 파일은 저장/공유 후 삭제됩니다.

안드로이드 저장 기능은 시스템 디렉터리 피커를 사용하며 결과를 반환합니다. `completed` 아니면 `canceled`iOS 저장 및 공유 기능은 시스템 공유 시트를 표시하고 다시 돌아옵니다. `presented`시스템 API는 최종 저장/취소 결과를 신뢰할 수 있게 보고하지 않으므로 `presented` 성공적인 저장이 이루어지지 않습니다.

페이지 처리 또는 계정 전환은 활성 네이티브 요청을 취소합니다. 이메일 계정 연동은 웹에서 이루어지며, 네이티브 OAuth 프로세스는 없습니다.

타입 검사 및 프로토콜/호스트 다운로드 테스트가 기록된 구현에서 성공했습니다. 캐시 지속성, 시스템 공유, 저장 기능은 여전히 iOS/Android 기기 인증이 필요합니다.
