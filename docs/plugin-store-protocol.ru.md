# Протокол магазина плагинов Doca v1

[中文](plugin-store-protocol.zh-CN.md)

Обновлено 2026-09-30, с текущими обязательными полями и примечаниями по навигации ниже. **Реализации удаленных магазинов используют этот протокол.** Это имеет приоритет перед ранее выпущенным проектом, связанным с полным каталогом и хранением ZIP-файлов в магазине; этот проект не является приемлемым контрактом.

Установка через ZIP/npm, общие архивы, восстановление запуска множества инстансов, удаленная пагинация, проверки обновлений, детали и навигация в Web/App реализованы в исходном коде. Внешние хранилища и независимые плагины все еще требуют выполнения нижеуказанных проверок; реализация в исходном коде не гарантирует, что все внешние сервисы работают. Текущий SDK `0.1.9`Проверьте примеры по сравнению с установленными версиями хоста и экспортом пакетов.

## 1. Обязанности и развёртывание

- Регистр npm распространяет полные предварительно скомпилированные пакеты. У магазина нет эндпоинта для скачивания ZIP-файлов; для проверки необходимо изучить саму сущность пакета в формате npm.
- Дистанционный магазин имеет метаданные, категории, релизы, процедуры одобрения/отмены, статистику лайков/западных скачиваний и подробные данные текста.
- Doca имеет полномочия администратора, операции установки, проверку целостности, общие архивы, работающие версии, записи в Web/App и шаблоны.
- Лайки и вход в GitHub происходят на удаленном сайте. Doca отображает количество лайков и предлагает новую страницу при клике. Он не собирает данные для входа, а также не использует API для лайков, OAuth-вызова или связывание аккаунта.
- Ручные установки через npm и локальные установки в формате ZIP/директории остаются поддерживаемыми. Пакеты, не входящие в обзорный каталог, помечаются как не прошедшие проверку; само распространение через npm не является официально утвержденным.

```dotenv
DOCA_PLUGIN_STORE_URL=https://store.smartdoca.cc
DOCA_PLUGIN_NPM_REGISTRY=https://registry.npmjs.org
DOCA_PLUGINS_DIR=/data/plugins
```

Адреса хранилищ/реестров без учетных данных, префиксов путей, запросов или фрагментов — это HTTP(S) источники. Пустые значения используют стандартные параметры. В версии 1 поддержка входа в частный реестр не предусмотрена. Сервер Doca-прокси хранит запросы без куки браузера, аутентификации, идентификаторов пользователей или бизнес-данных; удаленное сервису не требуется использование CORS-функции браузера.

Префикс API — `/api/v1`JSON имеет формат UTF-8, а ответы содержат поле protocolVersion:1. Время указано в формате UTC ISO 8601. Числа — неотрицательные безопасные целые числа, или null, если они неизвестны; неизвестные значения не должны равняться нулю. Все endpoints являются публичными, доступными только для чтения, и не требуют входа с помощью учетной записи.

## 2. Публичные типы

<a id="pluginsummary"></a>

### Краткое описание плагина

```json
{
  "id": "example.mail",
  "name": "Mail",
  "summary": "Send and receive mail across multiple accounts.",
  "author": { "name": "Example", "url": "https://github.com/example" },
  "categoryId": "productivity",
  "icon": null,
  "detailPath": "/plugins/example.mail",
  "targets": ["web", "mobile"],
  "review": "approved",
  "official": false,
  "latestVersion": "1.2.0",
  "downloads": { "count": 1234, "period": "last30Days", "source": "npm", "asOf": "2026-09-30T00:00:00Z" },
  "likes": { "count": 42, "asOf": "2026-09-30T00:00:00Z" },
  "updatedAt": "2026-09-29T12:00:00Z"
}
```

Ограничения:

- id совпадает с manifest.id и `^[a-z][a-z0-9]*(?:[.-][a-z0-9]+)*$`Максимум 100 символов.
- name/author.name: 1–160 символов; summary: максимум 300 символов; все в простом тексте.
- author.url: HTTP(S) URL или null, если речь идет только о кликах пользователя, без автоматического получения адреса хоста.
- categoryId: 1–60 символов, совпадение `[a-z0-9-]+`Получайте категории отдельно, а не выводите их из страницы.
- Иконка: PNG-данный URL или null, максимум 24 КиБайт кодированный; без SVG, скриптов или URL remote-изображений.
- detailPath: абсолютный путь same-origin `/plugins/<id>`Сочетается с настроенным источником. Отклоняются внешние источники, запросы/фрагменты и транзакции. Новые окна используют параметры noopener, noreferrer.
- Цели: непустой, отсортированный массив веб/мобильных приложений. Мобильные приложения – это приложения с контролируемым WebView, а не динамический нативный код.
- Отзыв: одобрено/приостановлено. По умолчанию список показывает значение «одобрено»; детали могут показывать «приостановлено».
- Официальное: необходимый булевый параметр, отдельный от процесса проверки релиза. Официальная идентификация отображается только в случае значения true, без попыток вывести её из источника установки. Отсутствие официальной идентификации – это сбой протокола.
- latestVersion: последняя одобренная стабильная версия или null; она не определяет возможности установки/обновления на конкретном хосте.
- Количество загрузок пакетов по npm за последние 30 дней указывает на загрузки пакетов, а не на количество пользователей/инсталляций Doca или загрузки по версиям.
- Необнаруженные статистические данные все еще возвращают объекты с количеством null/asOf. Списки не включают текст в ресурсном формате, исторические массивы релизов, tar-файлы и полную навигацию.

<a id="release"></a>

### Отпустить

```json
{
  "pluginId": "example.mail",
  "version": "1.2.0",
  "sdkRange": "^0.1.9",
  "dataVersion": "1",
  "targets": ["web", "mobile"],
  "mobileHostRange": "^1.0.0",
  "dependencies": [],
  "changelog": "Improve mail synchronization.",
  "review": "approved",
  "reviewedAt": "2026-09-29T12:00:00Z",
  "publishedAt": "2026-09-29T10:00:00Z",
  "npm": {
    "registry": "https://registry.npmjs.org",
    "name": "@example/doca-mail",
    "version": "1.2.0",
    "integrity": "sha512-BASE64_OF_SHA512_DIGEST",
    "size": 12345
  }
}
```

Вышеупомянутый дайджест является placeholder. Фактическая интегральность должна представлять собой одно значение SRI, содержащее стандартный Base64-дайджест SHA-512 длиной 64 байта. npm.size — это точная длина tgz архива, составляющая 1–33 554 432 байт. npm.version, Release.version, package.json.version и manifest.version должны совпадать.

Версия использует трехчастную форму semver, может включать предварительную версию, исключает метаданные сборки и имеет максимум 100 символов. sdkRange точно соответствует манифесту; текущая версия SDK — 0.1.9, а поддерживаемые диапазоны — `*`, точно, `^`и `~`mobileHostRange необходим для мобильных целевых устройств и относится к протоколу мобильного плагина-хоста (v1:1.0.0), который отличается от номера сборки App Store и совместимости SDK.

dataVersion соответствует `[a-zA-Z0-9._-]{1,80}` без заказа; обновления v1 требуют точного равенства. Навычно содержит не более 100 зависимостей `{id,range,optional?}` Зависимости плагина Doca, отдельные от зависимостей npm. Плагины, не имеющие зависимостей, не устанавливаются автоматически.

Обзор выпуска одобрен/отменен. Отмена предотвращает новую установку, при этом текущие версии автоматически не удаляются. Выпуски с более высоким номером npm не могут появиться в официальных рекомендациях без одобрения. Обзор связывает все это. `(pluginId,npm.registry,npm.name,version,integrity,size)`Та же версия не может заменить свой пакет. Авторы, статистические данные и отзывы могут измениться; объявления о размере/способностях пакета неизменны.

Changelog — это обязательный текстовый строка на endpoints release-list и exact-release, максимум 100000 символов. Пустая строка означает отсутствие примечаний; линии должны сохраняться без выполнения HTML-кодировки.

## 4. Пагинация поиска и порядок сортировки

`GET /api/v1/plugins?q=mail&category=productivity&target=mobile&sort=downloads&limit=24&locale=zh`

| Параметр | Правило |
| --- | --- |
| q | Опционально; максимальная длина — 100 символов; удаленные поисковые запросы: имя, краткое описание, автор, ID плагина и имя npm |
| категория | Опциональный ID категории; если не указано, значит все |
| цель | Опционально – веб/мобильная версия; отсутствие указано означает без ограничений |
| сортировка | обновлено (по умолчанию), загрузки, лайки, имя |
| ограничение | 1–48, по умолчанию 24 |
| курсор | Необязательный непрозрачный курсор, максимум 2048 символов |
| место | zh/en, по умолчанию zh |

```json
{
  "protocolVersion": 1,
  "items": [],
  "page": { "nextCursor": null, "total": 0, "snapshotAt": "2026-09-30T00:00:00Z" }
}
```

Элементы находятся внутри списка PluginSummary&#91;&#93;. Общее количество соответствует количеству результатов или равно null; null nextCursor означает последнюю страницу. Кнопка "Загрузить больше" добавляет только результаты из одного запроса. Изменение поиска, фильтра или порядка отменяет курсор; отмена старых запросов или игнорирование поздних ответов — вместо смешивания запросов.

Обновленные данные отсортированы по убыванию: updatedAt; загрузки – по количеству за последние 30 дней; лайки – по убыванию; имя – в порядке возрастания; локализованное имя. Все используют убывающий ID в качестве стабильного критерия для решения противоречий. Неизвестные статистические данные соответствуют известным значениям.

Курсоры связывают нормализованный запрос, порядок и снимок результатов; продолжение сохраняет снимок. Снимки действуют не менее 15 минут, чтобы избежать дубликатов/отсутствующих записей при изменении статистик. При истечении срока возвращается код 410 cursor_expired и запускается снова; при несоответствии параметров возвращается код 400 cursor_mismatch. Doca не должен скачивать весь каталог для выполнения локального поиска/сортировки/пагинации.

Страница имеет размер не более 2 МиБ с таймаутом в 15 секунд. ETag необязательный параметр; Doca отправляет If-None-Match только в случае совпадения кэшированного ответа, и использует этот кэш при статусе 304.

## 5. Детали и форматированный текст, доступ к которому только для чтения

`GET /api/v1/plugins/<id>?locale=zh`

```json
{
  "protocolVersion": 1,
  "plugin": { "id": "example.mail", "name": "See PluginSummary; return the complete object" },
  "description": {
    "format": "doca-slate",
    "version": 1,
    "nodes": [
      { "type": "heading", "level": 2, "children": [{"text":"Mail plugin"}] },
      { "type": "paragraph", "children": [{"text":"Supports multiple mail accounts.","bold":true}] }
    ]
  }
}
```

Сокращенный объект плагина на самом деле должен быть полным PluginSummary. Релизы разделяются по страницам. Дистанционное сервисное обновление/сохранение происходит с помощью slatetsx и преобразуется в транспортный подмножество ниже; Doca отображает его в режиме чтения без сохранения, редактирования или загрузки дистанционных плагинов редактора. doca-slate не принимает произвольные внутренние узлы slatetsx.

<a id="rich-text-v1-nodes"></a>

### Узлы rich-text v1

- Текст: `{text:string,bold?:boolean,italic?:boolean,underline?:boolean,strikethrough?:boolean,code?:boolean}`.
- парграф: `{type:"paragraph",children:Inline[]}`.
- Заголовок: структура абзаца с целочисленным уровнем от 1 до 6.
- Ссылка: встроенная `{type:"link",url:string,children:Text[]}`; Только https/http/mailto; отклоняются управляющие символы, JavaScript, данные URL; внешние окна используют нопенер, норерфер.
- blockquote: `{type:"blockquote",children:Block[]}`.
- список с пунктами/список с номерами: `{type:...,children:ListItem[]}`; list-item: `{type:"list-item",children:Block[]}`.
- код-блок: `{type:"code-block",language?:string,children:Text[]}`; отобразить простой текст без выполнения.
- изображение: `{type:"image",src:string,alt:string,children:[{text:""}]}`Пути передачи данных форматов PNG/JPEG/WebP: максимум 1 МБ данных для каждой изображения (1,048,576 байт). SVG/remote URL-адреса отклоняются для избежания запросов на использование приватных адресов и отслеживания. Версия Doca 0.1.5 и более ранняя сохраняет первоначальный лимит отображения в 256 КиБ; для больших изображений необходим клиент с обновленными параметрами. Это изменение лимита не влияет на миграцию или конвертацию данных; при возврате клиента его предыдущий лимит отображения восстанавливается. Общий размер данных не превышает 2 МБ.
- разделитель: `{type:"divider",children:[{text:""}]}`.

Неподдерживаемые узлы сохраняют текстовые элементы с частичным отображением информации. Неизвестные форматы/версии показывают явное сообщение и ссылку на детали удаленного сервиса, без выполнения HTML/JSX. Чистый HTML, скрипты, iframes, исполняемые компоненты и поля для обработки событий отклоняются. Ограничения: 5000 узлов, глубина 16, 200000 символов текста и общий объем ответа 2 МБ. Удаленный сервис преобразует неподдерживаемые таблицы/типы в абзацы/изображения. Новые типы требуют согласованных изменений в протоколе и рендере.

## 6. Выпуск и проверка установки

`GET /api/v1/plugins/<id>/releases?limit=20&cursor=...`

Возвращает `{protocolVersion:1,items:Release[],page:{nextCursor,total,snapshotAt}}` С использованием правил списка и ограничения 1–48. Сортировка по убывшему semver, приоритетом имеются одобренные стабильные версии; опционально includePrerelease=true. Отозванные версии доступны только путем точного поиска.

`GET /api/v1/plugins/<id>/releases/<version>`

Возвращает `{protocolVersion:1,release:Release}`Установка возвращает точное состояние ревью/сборки, а не старые списки. Неизвестные версии возвращают 404; отмененные версии указаны в ответе 200, и их нельзя установить.

<a id="npm-download"></a>

### npm download

1. Проверьте, что Release.npm.registry равен настроенному реестру (по умолчанию npmjs); магазин не может выбирать произвольные источники.
2. Получите точные метаданные версии. `GET /<encodeURIComponent(packageName)>/<encodeURIComponent(version)>`без последней/тег/диапазонной разрешения.
3. Проверьте имя/версию и целостность dist.integrity согласно утвержденному SRI, затем скачайте dist.tarball.
4. Tar-файл представлен в формате HTTP(S) на регистрационном адресе, без учетных данных/фрагмента; нет перенаправлений. Метаданные: 2 МБ за 15 секунд. Загрузка: 32 МБ за 120 секунд, точный размер и проверка по SHA-512.
5. Безопасно извлекать файл npmtgz в одном пакете/обёртке. Принимаются только обычные файлы/директории; отклоняются символьные/трудные ссылки, устройства, абсолютные/переменные/дублирующие пути. Пропускаются заголовки расширения pax x/g (используемые для mtime/xattr в библиотеке libarchive на npm/macOS), ни извлекаются они, ни не применяются их пути. Проверяется следующий путь ustar. Обязательно не более 10000 элементов и 128 МБ расширенных данных с ограничениями потоковой передачи.
6. Проверьте метаданные пакета/меню/ревью и опубликуйте полный статус архива/цели. Ни в коем случае не запускайте скрипты жизненного цикла npm, команду npm install или процессы скачивания для отсутствующих зависимостей во время выполнения программы.

Руководство npm использует те же проверки с точными метаданными из настроенного реестра, без официального проверки. Проблемы с хранилищем не мешают ручной установке; запуск установленного плагина не требует наличия npm/store.

## 7. Проверка обновлений по партиям

`POST /api/v1/updates/check`

```json
{
  "protocolVersion": 1,
  "host": { "sdkVersion": "0.1.9", "mobileHostVersion": "1.0.0" },
  "plugins": [
    { "id": "example.mail", "version": "1.0.0", "dataVersion": "1", "npm": {"registry":"https://registry.npmjs.org","name":"@example/doca-mail"} }
  ]
}
```

Присылайте 1–100 различных идентификаторов плагинов в каждом батч, максимум 128 КиБ. Подавать можно только метаданные установки, за исключением идентификаторов сайта, пользователей, конфигурации, контента и учетных данных. Doca использует большие наборы данных. Локальные пакеты без npm-оригината могут не указывать npm и проверять официальные релизы с одинаковым идентификатором, не меняя тихо источник установки.

```json
{
  "protocolVersion": 1,
  "checkedAt": "2026-09-30T00:00:00Z",
  "items": [
    {
      "id": "example.mail",
      "installedVersion": "1.0.0",
      "status": "update_available",
      "currentReview": "approved",
      "latestVersion": "1.2.0",
      "release": { "pluginId": "example.mail", "version": "Return the complete Release object" },
      "reason": null
    }
  ]
}
```

В ответе должно быть ровно одно значение на запрос, с использованием параметра installedVersion, чтобы старые ответы не могли соответствовать новой версии.

| статус | Значение |
| --- | --- |
| update_available | Вышеуровневое одобренное стабильное выпуск, совместимое с SDK/dataVersion/mobile host; выпуск завершен. |
| up_to_date | Нет более высокой одобренной стабильной версии; release=null |
| несовместимый | Существуют более новые версии без совместимого кандидата; release=null; причина = sdk/data_version/mobile_host |
| неизвестно | Неизвестный плагин или несоответствующий источник npm; релиз = null; причина = not_found/source_mismatch |

Текущий обзор одобрен/отменен/неизвестен. Сообщите отдельно о отмененных установленных версиях без автоматического удаления/отключения. Doca перепроверяет локальные зависимые плагины во время установки; удаленные рекомендации не могут гарантировать локальную графику зависимостей.

Выберите наиболее совместимую версию, а не тестируйте только самую последнюю. latestVersion – это наиболее одобренная стабильная версия, и она может превышать release.version. Doca самостоятельно проверяет версию, SDK, структуру данных и зависимости; удаленные рекомендации не подразумевают авторизацию.

Проверьте работу вкладки «Установленные/Можно обновить», разрешите ручное обновление и хранение кэша не более 15 минут. Установка аннулирует результат работы этого плагина. При ошибке отображается сообщение «неудача/неизвестно», а не «все актуально». Не предлагайте обновления при удалении. Сравните глобальные целевые версии; отображение состояния «версии/перезапуск» выполняется отдельно. Пакеты npm, не входящие в каталог, можно проверить версии из реестра, но без автоматической установки они остаются непроверенными.

Ответы в батчах: 2 МБ за 15 секунд. Частичные неизвестные параметры используют состояние элементов; ошибки сети/ограничения скорости/формата приводят к HTTP-ошибкам без выдуманных нормальных результатов.

## 8. Пакеты и навигация

npm tgz содержит package/package.json; локальный ZIP-файл содержит package.json напрямую, без оболочки.

```json
{
  "name": "@example/doca-mail",
  "version": "1.2.0",
  "type": "module",
  "files": ["manifest.json", "dist", "web"],
  "doca": {
    "dataVersion": "1",
    "storage": "host",
    "manifest": "./manifest.json",
    "server": "./dist/server.js",
    "web": {"directory":"./web","entry":"./index.js"},
    "mobileHostRange": "^1.0.0",
    "navigation": [{
      "id": "example.mail.inbox",
      "title": {"zh":"邮箱","en":"Mail"},
      "icon": "mail",
      "webPath": "/plugins/example.mail/inbox",
      "mobile": true,
      "allowedSlots": ["web.left","web.top","web.topRight","web.right","web.user","web.home","web.more","mobile.drawer","mobile.bottom","mobile.topRight","mobile.account","mobile.home","mobile.more"],
      "defaults": ["web.left","mobile.drawer"],
      "order": 60,
      "adminOnly": false
    }]
  }
}
```

Предпрошивать и собирать все зависимости во время выполнения; отсутствие alias-ссылок на исходные коды хоста, глобальных мостов или деревьев симлинков pnpm. `doca.storage: "host"` Это обязательно. Отсутствующие/другие значения отклоняются перед импортом кода при установке через ZIP/npm/store, импорте директории или восстановлении запуска, без по умолчанию/адаптеров. Сервер по умолчанию экспортирует фабрику; веб-версия по умолчанию использует хост=>bundle с вставленным React. Все методы сохранения данных используют сервисы хоста; плагины не могут выбирать локальное/дистанционное сохранение, создавать базы данных или поддерживать постоянные директории. Установленные плагины реализуют очистку бизнеса и удаление без удаления путей хоста; при неудаче установка сохраняется. См. также… [контракт хранения](plugin-horizontal-scaling.ru.md) Для управляемых возможностей и координации очистки.

У ID навигации статического package.json используется наместие, а webPath остается под ним. `/plugins/<plugin-id>/`Также необходимо регистрировать соответствующую страницу в веб-пакете. Максимум 30 записей. allowedSlots/defaults отброшены, а defaults — это подмножество. Нет мобильных слотов без объявления мобильности; для использования мобильных слотов необходимы веб-страница и mobileHostRange.

Текущие позиции также включают web.admin и web.leftMore. Для web.leftMore требуется явное объявление; web.more остается в верхнем правом углу. Смотрите. [Расширения UI](plugin-extensions.ru.md)web.right – это панель инструментов для ввода, а не автоматическое встраивание произвольных страниц в качестве боковых панелей. Вводные данные открывают страницы; команды, виды/представление панелей имеют отдельный публичный контракт.

Администраторы настраивают видимость веб/приложений, их положение, порядок и группировку в Doca. Расположение элементов не является настройкой удаленного магазина; плагины заявляют о стандартных параметрах и поддерживают только их. Переполнение kapаса использует опцию "More". Отключенные плагины исчезают из работающей навигации. Скрытая навигация не отменяет доступ к маршрутам/API; хост и плагины авторизуют каждый запрос.

Проверки проверяют соответствие целей фактическим данным из веб/мобильных приложений, sdkRange, dataVersion, зависимостями и идентификацией/версией пакета. Doca повторяет проверку. Релиз исключает полный навигационный процесс; пакет является источником функциональности.

Приложение должно сначала выпустить версию, включающую хост мобильного плагина. Последующие соответствующие страницы загружаются через контролируемые WebViews без загрузки/выполнения модулей React Native. Вход использует одноразовые тикеты хоста, а не долговечные токены приложения в скриптах плагина. Сфера навигации/вызовов хоста соответствует руководству по разработке.

## 9. Ошибки, кэш и отзыв

```json
{"protocolVersion":1,"error":{"code":"not_found","message":"Plugin not found"}}
```

HTTP-ошибки: 400 invalid_request/cursor_mismatch; 404 not_found; 410 cursor_expired; 429 rate_limited с параметром Retry-After; 503 unavailable. Сообщение — простой текст, не логический ключ. Не возвращайте HTML-коды входа, перенаправления или стек-трейсы. При неудаче сохраняется локальное управление и возможно повторное попытка; установка не может проходить без валидации.

Детали/точный кэш обзора должны длиться не более 60 секунд. При установке необходимо пересобрать точные версии без использования кэша в режиме оффлайн. Согласование не является абсолютной гарантией безопасности: серверные плагины выполняются в надежном процессе, а не в сандбоксе.

Внутренний анализ, публикация автором, вход в GitHub и подобные действия находятся в владении хранилища. Порядок публикации: опубликовать пакет npm → получить неизменные байты → провести анализ/сканирование → опубликовать одобренное релизное сообщение → обновить резюме/индекс поиска.

## 10. Множество экземпляров и активация

Установка хранит полные архивы и глобальное состояние цели в базе данных общего хоста; инстансы используют приватные директории плагинов для записи. Запуск проверяет/восстанавливает файлы и отклоняет частичные пакеты без доступа к npm/store. Отсутствующие/поврежденные общественные архивы отклоняются явно.

Установка, обновление, активация, отключение и удаление требуют перезапуска каждой инстанции. Система управления сообщает о версии работающей инстанции, не утверждая активации на всем кластере. Compose использует `docker compose restart doca`Kubernetes/operators постепенно перезапускают инстансы и отключают старый трафик для несовместимых API.

Исторические веб-ресурсы можно восстановить из общих архивов без требований к совместимости между версиями бизнес-API. Опубликованные схемы навигации вступают в силу после обновления клиента без перезапуска; изменения в возможностях пакета требуют обновления или перезапуска. Текущая демонстрация удаления выполняет очистку бизнес-системы, удаляет метки версий данных при успехе и сохраняет неизменные архивы. Реализованы процессы очистки управляемой базы данных и приватных объектов, а также физическое разделение их обработки. Процесс истощения бизнес-задач на всем кластере остается незавершенным; плагины не могут самостоятельно удалять директории.

## 11. Интеграционные фиксированные элементы

Предоставьте как минимум:

1. Пустые списки, длиннее двух страниц, фильтры по поиску/категории/платформе, четыре способа сортировки, истекшие/несоответствующие курсоры.

3. Отключение страницы пагинации; последняя несовместимая, но менее совместимая обновка; все обновления несовместимы; отменен установленный релиз; неизвестный/несоответствующий пакет.
4. Проверил количество байт в npm и реальное SRI/размер; отклонял замененные пакеты, несоответствия в дигестах/описаниях, перенаправления и процессы экстракции.
5. 429/503 – отказы в работе; ошибки хранения не должны нарушать локальные списки установленных приложений или текущое использование приложения.
6. Установите на одном экземпляре; перезапустите другой с пустой директорией и без работы npm/store; восстановите данные из общей архивы и исправьте поврежденный локальный кэш.
7. Декларации/навигация в веб-приложениях/аппаратных приложениях; отказ в входе в приложение без декларации для мобильных устройств; отклонение несовместимых обновлений данных.
8. Клики открывают настроенную страницу деталей same-origin без вызова API для кликов или запуска Doca OAuth.

Смотри [Разработка плагинов](plugin-development.ru.md) и [Границы SDK](plugin-sdk-contract.ru.md)Для хост-API используйте реально экспортированные типы; для удаленного хранилища используйте этот сетевой протокол. Не выделяйте предложенные методы хоста.

## Прием в различных репозиториях

Бегать `pnpm exec tsx scripts/verify-plugin-store-contract.ts ../doca-plugin-store`Он использует реальные маршруты магазина с базой данных в памяти для категорий (включая нулевые количества), поиск, целевые объекты, пагинация, детали, релизы, обновления и истечение срока действия курсора, не влияя на бизнес-базы данных или процесс публикации npm.

/categories — это список категорий, а не произвольное множество тегов; у каждого плагина есть один categoryId. Количество категорий охватывает все опубликованные плагины независимо от поиска; page.total отражает снимок запроса. Неизвестные загрузки/лайки отображаются как дробь, ноль — как 0.

Обзор подтверждает тот же статический навигационный интерфейс, что и у хоста: двуязычное название (1–80 символов каждое), иконка, порядок элементов, допустимые поля, действующие значения по умолчанию и отсутствие неизвестных полей. Сервер построен на JS/mjs/cjs, веб-интерфейс — на JS, манифест — статический JSON. Ни обзор, ни установка не выполняют скрипты установки пакетов.
