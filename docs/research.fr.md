# Enregistrements de recherche et d’acceptation

[中文](research.zh-CN.md)

Les notes d’implémentation, les propositions et les archives d’acceptation historiques ont des scopes de version différents. Une proposition, une restriction ancienne ou un test passé ne définissent pas le comportement actuel ; utilisez les guides publics, les inventaires d’implémentation des contrats et les notes de sortie correspondantes. Les archives originales conservent leur langage, les dates et le champ de vérification. Les liens provenant de sources de dépôts de navigation publique sont ouverts.
