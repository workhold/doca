# 瀏覽器助手

[English](browser-assistant.md)

瀏覽器助手將網頁選區或當前頁面已載入的內容與圖片儲存到 Doca，並提供個人 AI 對話側欄。入口為個人選單 → **瀏覽器助手**，或 `/#/browser-assistant`。

<a id="安装与登录"></a>

## 安裝與登入

1. 在「收錄方案」設定儲存目錄，以及每次新建文件或追加到指定富文字 / Markdown 文件。標題模板支援 `{title}`、`{date}`；可以設定預設方案和 AI 整理要求。知識冊生成頁面不接受直接追加。
2. 點選設定頁上方的「下載已配置擴充套件」並解壓。Chrome / Edge 的擴充套件管理頁中開啟開發者模式，選擇「載入已解壓的擴充套件程式」。Manifest V3 最低要求 Chromium 116；ZIP 不能直接點選安裝，當前未提供商店或企業簽名分發。
3. 安裝包只含 Doca 站點地址，**沒有賬戶憑證和啟用有效期**。開啟外掛時，已有 Doca 登入會話會自動完成授權；沒有登入時開啟 Doca 正常登入頁，登入後返回外掛繼續使用。安裝前已開啟的網頁重新整理後會顯示右側工具條；從瀏覽器擴充套件入口收錄時也會按需載入指令碼。
4. 網站退出、會話過期或被撤銷後，該網站會話繫結的外掛授權也失效。單純關閉 Doca 標籤頁不等於退出登入。同一瀏覽器切換賬戶時重新載入該賬戶的方案和 AI 狀態；原賬戶的未提交任務按連線隔離，切換回來可以繼續。

外掛不讀取或複製網站登入 Cookie。登入交接在 Doca 同源頁面完成，使用 60 秒單次授權碼和 SHA-256 校驗的隨機 verifier，換取 10 分鐘的受限訪問憑證。憑證只儲存在擴充套件可信上下文的瀏覽器會話儲存中，並自動重新驗證；服務端只儲存雜湊，每次檢查對應網站會話及連線狀態。瀏覽器阻止擴充套件攜帶網站 Cookie 時，透過同源頁面驗證；後臺被動輪詢最多複用 30 秒內的同源驗證結果，使用者收錄和 AI 操作會重新核對。

<a id="收录方案的保存位置"></a>

## 收錄方案的儲存位置

「每次新建文件」使用與文件移動相同的樹形位置選擇框。可選擇「個人文件」、某個知識庫根目錄，或展開知識庫，選擇具體文件下方。知識庫列表單獨分頁，不受最近文件數量影響；「載入更多知識庫」繼續顯示下一頁。選擇方案儲存後，再次開啟會自動展開並定位到原來的位置。

選擇器展示當前賬號可寫入的普通知識庫，並保留庫內目錄層級；不能寫入的文件置灰，仍可展開檢視可寫子節點。目錄載入失敗可重試，當前選擇不會改成其他位置；失效或無寫入許可權的位置會阻止儲存。超大知識庫遵守現有目錄介面的 10,000 節點上限，並顯示提示。知識冊生成內容仍不接受瀏覽器收錄。「追加到指定文件」繼續使用文件搜尋。

## 收錄、AI 和切換地址

普通網頁右側常駐五個入口：**收錄當前頁面、收錄選中區域、Doca 助手、開啟 Doca 網站、設定**。「開啟 Doca 網站」在新標籤頁開啟當前配置的站點，未登入時也可使用；未配置或地址無效時開啟外掛設定。拖動頂部把手可以上下移動整組圖示，位置會儲存在本機，重新整理、新開網頁或重啟瀏覽器後恢復；聚焦把手時也可使用方向鍵、Home 和 End 調整。設定下方同列的箭頭可收起/展開工具條，收起後仍能拖動。讀取位置快取後再顯示，避免初始跳位。選擇網頁文字不會額外彈出圖示或工具欄。

點選收錄圖示，在氣泡的自定義下拉框中核對收錄規則和目標，再點選「確認收錄」。選區收錄需先選中文字；整頁包含當前頂層 DOM 已載入的內容，包括視口之外的部分。預設預選 Doca 的預設規則，也可以切換其他規則。每次開啟氣泡會重新核對登入和規則；連線暫時失敗可重試，未配置規則時提供設定入口。失敗後在氣泡中重試，或在擴充套件彈窗點選「重試上次收錄」，沿用原請求及材料，不重複生成文件。未提交材料儲存在當前瀏覽器會話，關閉整個瀏覽器後可能需要重新選擇。更新或重新載入外掛後，舊指令碼會提示重新整理當前網頁。

點選「Doca 助手」開啟瀏覽器右側助手，使用與 Doca 相同的對話介面、模型選擇、Markdown、進度和審批。開啟助手不會呼叫模型；傳送新訊息時讀取當前標籤頁的最新頁面。切換標籤、導航或網頁內路由後，引用跟隨當前頁面，不需要勾選附加網頁。單條訊息重試仍使用原訊息的材料。頁面圖片不支援或讀取失敗不阻斷 AI 閱讀正文；完整收錄仍要求圖片齊全。歡迎頁提供收錄網頁、總結頁面、提煉要點和整理收錄四個提示。AI 使用 Doca 配置的模型、計量和審批流程，生成的會話可以在 Doca 中繼續。連線預設可以使用 AI，使用者可在 Doca 編輯連線名稱及 AI 開關；實際請求仍受賬戶許可權及模型策略約束。

新會話在首條訊息被接收時，以網頁名稱、請求和域名生成標題，來源使用瀏覽器圖示標識。新訊息附加的網頁進入「操作過的資源」，網站和外掛中均可檢視並在新標籤頁開啟，同一網址只保留一個關聯條目；這些連結不授予文件許可權。規則修改後，上次會話若繫結舊規則版本，重新開啟助手會使用當前選中規則的新輸入器，舊會話和待傳送訊息保留；不會把舊任務自動改成新規則。既有標題和舊會話不回填改寫。

當前擴充套件版本為 **0.2.11**。開啟擴充套件後會核對當前 Doca 站點提供的外掛包版本；保持開啟時隨連線重新整理檢查，檢查間隔至少五分鐘，也可在外掛設定中手動「檢查更新」。發現新版時，彈窗和 AI 側欄顯示提示，點選「前往 Doca 下載新包」進入當前站點的下載頁。Doca 下載區展示版本和完整包名，ZIP 檔名為 `doca-browser-assistant-<版本号>.zip`，版本來自擴充套件的 `manifest.json`，與 Doca 服務端版本分別管理。更新 Doca 後，需重新下載並在 Chrome / Edge 重新載入擴充套件；僅更新服務端不會更新已安裝的外掛。普通收錄不需要 AI 模型，AI 側欄需要站點已配置並允許使用的模型。

版本核對只提示本站存在更新包，不判斷協議相容性、不限制業務操作。版本介面缺失、響應無效或網路失敗均顯示「無法檢查更新」，不推斷相容或已是最新版。不修改配置、授權和待傳送資料格式，不遷移或清理歷史資料。此功能首次安裝仍需手動更新擴充套件；舊擴充套件不會因服務端更新而自動獲得提示能力。

普通 HTTP(S) 網頁在導航後或安裝前已開啟、尚無抓取指令碼響應時，收錄會在當前網頁的頂層框架按需載入擴充套件自帶指令碼並重試一次，無需重新整理網頁。擴充套件為此宣告 `scripting` 許可權，繼續使用已有的 HTTP(S) 站點訪問範圍；瀏覽器限制頁面及被拒絕的站點訪問仍會明確報錯。

新的 AI 傳送在清空輸入器之前，先以事務儲存到 IndexedDB，並按 Doca 站點、賬戶、連線及所選規則隔離。正在傳送、傳送失敗及已接收的訊息在對話中顯示一次；待傳送列表只顯示等待傳送的訊息，不等待 AI 正式回覆才消失。重新整理後繼續使用原訊息 ID；後端已接受的任務先核對，不重新捕獲網頁或提交。原 localStorage 中的舊待傳送訊息保留原文，需逐條明確繼續或撤回，並選擇當前模型和範圍。

點選右側工具條的設定圖示開啟獨立設定頁，可進入 Doca 的收錄規則設定，也可直接修改 **Doca 服務地址**，填寫例如 `https://doca.example.com`，不含 `/api/v1`、其他路徑或查詢引數。擴充套件彈窗內也保留設定入口。也可以在 Doca 複製站點配置，再貼上到外掛的摺疊配置區域。生產地址要求 HTTPS，本機迴環地址允許 HTTP。切換後驗證新站點當前登入賬戶；原站點的未提交任務不會自動傳送到新站點。地址配置格式是嚴格的 `{ "version": 2, "origin": "https://doca.example.com" }`。

<a id="撤销与恢复"></a>

## 撤銷與恢復

在 Doca「瀏覽器連線」中撤銷一個連線或全部連線。撤銷會使訪問憑證及待兌換授權碼失效，取消相關瀏覽器 AI 任務；網站仍登入也不會自動恢復該連線。恢復時必須在 Doca 點選該連線的「恢復連線」，然後返回外掛重新連線。外掛不會透過自動建立另一條連線來繞過撤銷。

撤銷、退出和更換站點均不刪除已儲存文件、原圖或 AI 會話，也不能回滾已經提交的事務。普通網站發起的 AI 任務與瀏覽器任務分別管理；同一會話在 Doca 內繼續的普通任務不會因外掛連線撤銷而取消。執行中瀏覽器任務的後續工具及提交檢查當前網站會話，當前宿主會在退出後取消對應任務；其他執行器透過任務心跳及操作邊界複查。

<a id="内容边界"></a>

## 內容邊界

收錄保留語義文字、標題、列表、程式碼、連結、常規表格、來源連結和圖片，不復刻網頁 CSS 或互動。未載入的資料、分頁、iframe、關閉的 Shadow DOM、虛擬列表、畫布和影片不屬於完整歸檔範圍。靜態 SVG 圖片和內聯 SVG 經本地清理後轉為保留透明背景的 PNG；移除指令碼和事件屬性。依賴外部資源、內嵌 HTML、動畫或無法渲染的 SVG 改為文字佔位。

圖片支援 PNG / JPEG / WebP / GIF。本次新收錄的靜態圖超過 **4 MiB 或 2500 萬畫素**時，上傳前自動壓縮至不超過 4 MiB、最長邊不超過 4096、總畫素不超過 1600 萬；保持原編碼格式，保留 PNG / WebP 透明通道，並按 EXIF 方向處理。未超閾值的圖片保留原位元組。GIF、動態 WebP 和 APNG 不轉成靜態圖，超過原有 20 MiB 或 2500 萬畫素上限時改為帶原因的佔位。已儲存圖片及重試時已上傳的圖片不重新處理。靜態原始輸入最多讀取 64 MiB、解碼前最多允許 1 億畫素。SVG 原始檔案限 32 MiB，以限制擴充套件訊息大小。SVG 輸出最長邊不超過 4096、總畫素不超過 1600 萬，再按 PNG 規則壓縮。

服務端單張圖片上限仍為 20 MiB / 2500 萬畫素，每次最多 100 張、合計 100 MiB；正文最多 512 KiB。新收錄先完成圖片預處理，再建立任務。不支援、無法讀取或轉換失敗的圖片，在原位置寫入缺圖說明、原因及原始 HTTP(S) 來源連結，正文和其他圖片繼續儲存；blob/data 臨時地址不寫成永久連結。許可權、配額及儲存故障仍阻止儲存。任務建立後，正文、圖片清單和請求 ID 凍結，上傳時才發現的圖片處理失敗也在提交時改為佔位；網路、許可權、配額及實際儲存寫入錯誤仍中止提交。暫存任務 24 小時到期；清理只移除未繫結文件的物件。

擴充套件 0.2.6 繼續使用既有 v1 收錄協議和點陣圖資產格式，不改資料庫。使用者已同意：已儲存文件、已上傳圖片及歷史失敗任務保持原樣；更新並重新載入擴充套件和原網頁後，為舊失敗頁面重新發起收錄。舊任務不自動轉換或重發，仍按原到期規則清理；回退無需轉換資料，並保留已有文件和任務。不自動改寫暫存內容或歷史文件。

AI 僅開放當前方案範圍內的有限檢索、讀取、收錄和富文字 / Markdown 操作，繼續檢查賬戶當前許可權。沒有任意網路、指令碼、外掛工具或通用網頁自動操作入口，網頁文字不能擴大許可權。

<a id="升级与开发"></a>

## 升級與開發

升級或回退前，先停止佇列傳送並關閉所有舊版 Doca 網頁和瀏覽器助手，不同時執行新舊傳送器。保留 localStorage、IndexedDB、已保留的墓碑及之後的資料。回退保持佇列傳送停用，不將新儲存導回 localStorage，也不自動啟用舊傳送器；舊版缺少安全停用傳送功能時，不能恢復舊佇列傳送。見[獲批的保留與回退約定](verification/issue-tracker-2026-10-21/ai-pending-idb.md)。

首版上線前按使用者確認替換了原先的一次性啟用包和 180 天 token 方案：舊 v1 配置、啟用端點和 token 不再接受，也不自動轉換；已建立的方案、文件、附件、會話及原憑證記錄保留。更新擴充套件後使用新站點配置並重新登入連線。服務端、Web 和擴充套件應同步更新；不提供舊認證回退或混用方案。

擴充套件檔案位於 `apps/browser-extension`。`pnpm build:browser-extension` 將共用 AI UI 構建到本地 `generated/`，已包含在 `build`、`dev` 和 `dev:workspace` 中。服務端將固定擴充套件檔案、本地構建資源及公開站點配置一起生成 ZIP，不載入遠端指令碼。原始碼部署和 Docker 映象均需包含這些構建資源。當前 DDL 在原五張表之外增加兩張空的網站會話 / 授權碼錶，不提升資料庫相容代際、不回填舊憑證。見[資料庫升級約定](database-schema-evolution.zh-Hant.md)及[登入改造驗收記錄](verification/browser-clipper-login-2026-10-21/README.md)。

擴充套件 0.2.6 對外層帶連結的圖片和 SVG 分別儲存圖片與目標連結，避免巢狀 Markdown 導致整篇轉換失敗。已透過 Nature 原頁面完成收錄、開啟和重新整理驗收，見 [Nature 收錄驗收](verification/nature-capture-2026-10-26.md)。

擴充套件 0.2.10 與 Doca 0.2.22 對不支援的嵌入媒體保留佔位，接受可恢復的轉換警告；解析異常時保留原始文字。儲存成功旁列出本次請求的失敗資訊，不在資料庫或凍結任務中儲存報告；已完成任務冪等重試，不重放歷史報告。見 [Annual Reviews 收錄驗收](verification/annualreviews-capture-2026-10-26.md)。

整頁收錄會排除 CSS 隱藏的重複內容。原生格式轉換若超過既有新文件匯入預算，服務端將完整原文分段儲存為純文字，保留標題和已上傳圖片，並提示格式降級；源內容、授權、配額和儲存限制仍有效。見 [0.2.21 發行說明](releases/0.2.21.zh-CN.md)。

每次新收錄在十個名額已滿時，自動回收最舊且 30 分鐘沒有上傳或重試活動的任務；有關聯活躍瀏覽器 AI 任務的連線受到保護，原文和圖片仍保留到原定 24 小時期限。擴充套件 0.2.10 會使用同一份凍結材料重建過期收錄並重試一次，無需使用者手動清理。見 [0.2.22 策略和回退要求](releases/0.2.22.zh-CN.md)。
