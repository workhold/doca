# Настройка

Десктопный клиент Tauri включает в себя веб-фронтенд и подключается к отдельно настроенному удаленному хосту. Он не предоставляет локального бизнес-хоста и не изменяет конфигурацию развертывания удаленного хоста. См. [десктопный клиент](desktop-client.ru.md).

[中文](configuration.zh-CN.md)

Выберите `docker.env.example` для Compose и `.env.example` Для разработки источника, затем скопируйте его в корень репозитория. `.env`Они используют разные источники и пути к базам данных; оба показывают `/data/storage` Для постоянного файлового тома контейнера. Для разработки исходного кода измените корневую директорию хранения на абсолютно записываемую директорию на вашем компьютере. Не меняйте источники и не коммитите секреты.

<a id="required-compose-settings"></a>

## Необходимые настройки композиции

| Переменная | Требования | Пример с одним сервером |
| --- | --- | --- |
| `DOCA_ORIGIN` | Необходимо явно указать как HTTP(S) оригинальный источник. | `https://doca.example.com` |
| `DOCA_FILE_STORE_ID` | Должно быть непустым; должно указывать на магазин в JSON-формате | `local` |
| `DOCA_FILE_STORES_JSON` | Должно быть непустым; корректная конфигурация версии 1 с физическим сервером | Смотрите ниже |
| `DOCA_CREDENTIAL_MASTER_KEY` | Необходимо при каждом запуске; ровно 64 шестнадцатеричных символов (32 байта). | Генерируйте с `openssl rand -hex 32` |

```dotenv
DOCA_ORIGIN=https://doca.example.com
DOCA_FILE_STORE_ID=local
DOCA_FILE_STORES_JSON='{"version":1,"stores":{"local":{"provider":"local","root":"/data/storage"}}}'
```

Для новой установки с одним сервером, **Измените публичный источник и замените ключ учетной записи публичного примера** с выходом `openssl rand -hex 32`Необходимые значения для хранения файлов уже предоставлены. PostgreSQL, Redis, ключи моделей и учетные данные SSO зависят от условий. Существующие развертывания должны сохранять свои оригинальные мастер-ключи.

Используйте HTTP(S) источник без учетных данных, подпатчей, запросов или фрагментов. Корневой слеш в конце строки приводится к нормализации. В продакшене принимаются как HTTP, так и HTTPS. Прокси сохраняет настроенные параметры. `Host`Запрос, адресованный только… `127.0.0.1` не проходит проверку хоста. Смотрите [проверки здоровья](deployment.ru.md#start).

<a id="defaults-depend-on-the-entry-point"></a>

## Отказы зависят от точки входа

| Пункт входа | Происхождение | База данных / файлы | Мастер-ключ криптоключей |
| --- | --- | --- | --- |
| Резервный хранилище Compose | Требуется `.env` | SQLite `/data/doca.db`; требуется ID файла/JSON `.env`; `doca_data` установлено на `/data` | Необходимо; используйте постоянный ключ развертывания |
| Опубликованное изображение без Compose | Необходимо указать HTTP(S) оригинальный адрес. | Изображение явно указывает значения по умолчанию для SQLite и локального хранения. `/data`; установить постоянное подключение `/data` собственно ты | Необходимо; используйте постоянный ключ развертывания |
| Разработка источника | `http://127.0.0.1:39130` | SQLite `./data/v1/doca.db`; требуется ID файла/JSON, предоставленный `.env.example` | Необходимо; заменить публичный примерный ключ |

Парсер источника файлов-хранилищ не имеет имплицитного значения по умолчанию; значения для изображений являются явными значениями из окружения Dockerfile. Локальное хранение требует записываемого постоянного корня. S3 требует `bucket`, `region`, булево `forcePathStyle`и явно `credentials:{accessKeyId,secretAccessKey,sessionToken?}`Опциональный эндпоинт должен быть HTTP(S) корневым источником без учетных данных, подпатрона, запроса или фрагмента. Явные HTTP-эндпоинты поддерживают надежное внутреннее хранилище объектов, такое как RustFS; оператор контролирует доступ в сети, а сайт, активы и источники CDN также принимают HTTP(S). Учетные данные AWS shell не заменяют эти поля JSON. См. [хранение файлов](storage.ru.md) Для примера конфигурации RustFS.

Идентификаторы магазинов и физические места хранения должны оставаться доступными после записи объектов. Настроенный текущий идентификатор магазина должен соответствовать зарегистрированному активному идентификатору; изменение идентификатора, пути или баков не перемещает данные. Не изменяйте эти значения в качестве скорого способа миграции.

## Условные настройки и опциональные серверы

| Зависимости | Когда нужно / по умолчанию |
| --- | --- |
| `DOCA_DATABASE=postgres`, `DOCA_DATABASE_URL` | Для выбора PostgreSQL необходим URL; стандартный база данных — SQLite |
| `DOCA_DATABASE_POOL_MAX` | Основные соединения с базой данных по процессу; по умолчанию 10 |
| `DOCA_WEBHOOK_DATABASE_URL` | Опциональная эксплицитная база данных PostgreSQL; в противном случае она определяется как описано ниже. |
| `DOCA_REDIS_URL` | Необходимо для событий между инстансами, присутствия и лимитов скорости; если не задано, используются локальные реализации для процесса |
| `DOCA_REDIS_PREFIX`, `DOCA_INSTANCE_ID` | Префикс по умолчанию `doca`ID экземпляра по умолчанию равно случайному ID процесса |
| `DOCA_TRUST_PROXY` | IP-адреса/CIDR-области прокси, разделенные запятыми; **Никакой прокси не считается надежным по умолчанию**, включая loopback |
| `DOCA_PLUGINS_DIR` | Подготовленный каталог для установки/каша; Compose по умолчанию… `/data/plugins` |
| `DOCA_PDF_PYTHON` | Экземпляр Python с зафиксированными зависимостями WeasyPrint для экспорта в формате PDF; по умолчанию `python3`, `/opt/doca-pdf/bin/python` в Docker. Устарело `DOCA_PDF_CHROMIUM` отклонено |
| `DOCA_PLUGIN_STORE_URL` | HTTP(S) источник; стандартный вариант `https://store.smartdoca.cc` |
| `DOCA_PLUGIN_NPM_REGISTRY` | Регистр предустановленных пакетов; по умолчанию `https://registry.npmjs.org` |
| `DOCA_ASSET_BASE` | Опциональный префикс для строительных материалов; пустой значение `/assets` из Докы |
| `DOCA_AI_IMAGE_MAX_ATTEMPTS_PER_PAGE` | Представляются запросы на предоставление оплаченных изображений по каждой странице источника; по умолчанию 5, если не установлено значение. Требуется положительное безопасное десятичное целое число; значения 0, пустые или некорректные не позволяют запустить систему. |
| `DOCA_AI_IMAGE_SEGMENT_PROFILE` | Опциональный абсолютный путь к доверенному, строгому профилю SAM2 версии 1; если параметр не установлен, сегментация отключается. Неправильно составленная конфигурация приводит к нестабильной работе; недоступный проверенный рендер не позволяет использовать инструмент. Смотрите [локальная сегментация](ai-image-segmentation.md) |

Лимиты запросов изображений фиксированы при запуске сервера. Например, установите `DOCA_AI_IMAGE_MAX_ATTEMPTS_PER_PAGE=10` в источнике или Compose `.env` Необходимо перезапустить сервер или создать новый контейнер. Все реплики должны использовать один и тот же лимит. Повторные попытки, возобновление работы, изменение запросов или повторная регистрация партии не сбрасывают накопленные попытки. Считаются запросы, находящиеся в ожидании или неопределенные; экспорты и локальная рекомпозиция не учитываются. Существующие изображения, записи запросов и данные использования остаются нетронутыми. Снижение лимита отклоняет дальнейшие платные запросы, включая повторное использование полученных платных попыток, чье порядковое число теперь превышает лимит; эти записи никогда не пропускаются или не преобразуются. Версия 3 партии и версия 1 платных попыток остаются неизменными; более старые форматы партий все еще отклоняются без миграции.

Отсутствующий, пустой или некорректный главный ключ приводит к невозможности запуска, включая развёртывание без плагинов. В runtime нет по умолчанию ключа. Значение public в примерах файлов необходимо заменить для новой установки. Сгенерируйте один раз… `openssl rand -hex 32`Сделайте копию отдельно, и используйте ту же клавишу для каждой реплики/перезагрузки. Смотрите [Управляемые учетные данные](plugin-credentials.ru.md).

Передача через webhook всегда использует отдельную базу данных. SQLite создает `webhooks.db` Параллельно с основным базой данных. PostgreSQL по умолчанию… `<main_database>_webhooks`Несуществующая база данных вызывает попытку её создания. Если у учетной записи нет прав на создание базы данных, сначала создать эту базу данных и предоставить доступ, или установить `DOCA_WEBHOOK_DATABASE_URL` в доступную специализированную базу данных. Сервис хранения ИИ использует `ai.db` в Compose и `doca_ai` Схема в основном базе данных PostgreSQL; права PostgreSQL должны позволять её инициализацию. Эти хранилища требуют резервного копирования даже в случае отсутствия настроенной внешней модели ИИ.

Множество реплик требуют совместного использования PostgreSQL, Redis и файлового хранилища. Изменение переменной не передаёт существующие данные. Чтение [горизонтальное масштабирование](horizontal-scaling.ru.md) и [требования к выпуску](releases/0.2.24.md).

## Срок жизни логина

`DOCA_SESSION_TTL_SECONDS` Контролирует браузер, сессионные режимы QR-входа и WebView, включая истечение срока действия базы данных и сессионные куки `Max-Age`По умолчанию `86400` секунды (24 часа). `DOCA_MOBILE_SESSION_TTL_SECONDS` Контролирует мобильные сессии пользователей и их существующий процесс обновления; по умолчанию `15552000` секунды (180 дней). Оба принимают десятичные целые числа от 1 до 2147483647. Пустые, нулевые, отрицательные или некорректно формированные значения не позволяют системе запуститься. Компонент Compose передаёт обе переменные явно.

```dotenv
DOCA_SESSION_TTL_SECONDS=86400
DOCA_MOBILE_SESSION_TTL_SECONDS=15552000
```

Перезапустите для применения изменений в развертывании. Уже выданные сессии браузера сохраняют своё хранимое истечение срока; новые входы используют новый срок действия, а обновления для мобильных устройств — конфигурированный срок действия для мобильных устройств. Ни строки сессий, ни хранящиеся форматы не конвертируются. Куки сессий и flow аутентификации не изменяются. `Secure` В HTTPS, в то время как HTTP остается `HttpOnly` и существующая политика SameSite. Сайты HTTP используют `ws` для реального времени соединений.

Утвержденный адаптер браузера для HTTP предоставляет UUID v4. `crypto.getRandomValues` когда `crypto.randomUUID` Отсутствует, и предоставляется только SHA-256 `crypto.subtle.digest` через закрепленное `@noble/hashes` когда `crypto.subtle` Отсутствует. Нативные реализации остаются в использовании, когда они есть. Дigest соответствует нативным байтам; существующие идентификаторы, суммы электронных таблиц и форматы документов не конвертируются. Это не предоставляет возможности для других операций WebCrypto.

Кнопки копирования текста используют один общий помощник. Если доступен нативный буфер обмена, он используется; в противном случае одобренный HTTP-адаптер копирует текст через временную текстовую область. `document.execCommand("copy")`Восстанавливает фокус и выбор, а также сообщает о ошибках. Оно никогда не читает системный клипборд и не считает неудачную копию успешной.
