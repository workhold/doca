# 能力と限界

[中文](features.zh-CN.md)

このページは、現在のソースとホストについて確認されました。 **0.2.25** そしてプラグインSDK **0.1.11** 2026年10月29日。ビジネスプラグインをインストールする前に、ホストは以下のコア機能を提供します。各独立したプラグインは、自身の機能、バージョン、受け入れ結果を記述します。

<a id="independent-plugins-and-removed-features"></a>

## 独立したプラグインと削除された機能

- **簡単なメモ** ホストから削除されました。何もありません。 `#/notes` ページ、 `/api/v1/quick-notes` API、 `quick_notes` テーブル、または `quick_note_compilations` テーブル。以前のガイドは、ただ保持されているだけです。 [研究記録](research.ja.md); そのインターフェースは現在のホストでは使用できません。このリポジトリでは、クイックノートプラグインのリリースや現在の機能の保証はありません。
- メール、カレンダー、会員制、ポイント、請求、ビジネスクォータ、コンテンツモデレーションは独立したビジネスプラグインに属します。デフォルトの画像ではこれらのビジネス機能は一切インストールされません。登録審査とセキュリティ監査は依然として主要な機能です。
- テンプレート、資料、資料コレクション、およびプラグインドキュメント要素には、ホストインターフェースとピッカーがあります。 **ゼロデフォルトプロバイダー**SDKに合わせたプロバイダーを別途インストールする。以前のホストテンプレート管理CRUDページは存在しない。プロバイダーなしでも空白文書の作成は可能である。
- [例](../examples) サポート開発と孤立した受け入れ。デフォルト画像ではそれらをインストールせず、その結果は独立したビジネスプラグインを検証できません。

<a id="unavailable-or-requiring-separate-verification"></a>

## 利用できない、または別途確認が必要

- エディターには持続的なローカルレプリカと認可されていない更新キューがあり、利用可能な承認済みレプリカと正常なブラウザ保存が必要です。これは完全なオフラインアプリケーションやオフラインコールドスタート保証ではありません。OIDCプロバイダーとしてのDocaやSAMLは利用できません。詳細は [共同編集](collaboration.ja.md).
- プラグインによる一時的なワークスペース、クラスター全体でのビジネスタスクの消費、任意のSQL、および分散型クロスサービストランザクションが利用できません。ターゲットSDK契約では既存のエクスポートが確立されません。詳細は参照してください。 [実施状況](plugin-sdk-contract.ja.md).
- ネイティブプラグインのWebViewコンテナにはソースプロトコルがあります。iOS/Androidのビルド、デバイス動作、および独立したプラグインの統合にはそれぞれの受け入れが必要です。サーバーでのインストールでは、ネイティブJavaScriptをダウンロードして実行することはありません。
- 実際のAI、SSO、検証ゲートウェイ、Webhook、S3/CDN、その他のサービスはデプロイ設定に依存します。過去のリリーステストはそれぞれ定義された範囲を持っており、すべての外部サービスやデバイスを検証するわけではありません。
