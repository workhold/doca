## 참고 자료, 리소스, 찾기

내부 참조는 안정적인 UUID와 상대적 값을 유지합니다. `#/r/{id}` 위치 정보. 참조는 사용자 UUID를 유지하며 현재 디렉터리 정책을 준수합니다. 앞뒤 참조는 읽기 권한을 다시 확인해야 하며, 참조는 접근 권한을 부여하지 않습니다.

이미지, 첨부파일, 그리고 자료는 호스트 리소스 콜백을 사용합니다. 진행 상황, 취소, 오류, 지연 콜백은 원래의 대상에 고정됩니다. 다운로드는 권한을 부여하여 처리됩니다. `assets/:id/content?download=1`물리적 저장 위치는 내구성 있는 참조가 아닙니다.

서식 있는 텍스트와 스프레드시트가 안정적입니다. `onAttachmentPreview` 설치된 편집기로의 콜백. 서식 있는 텍스트가 제공됩니다. `AttachmentElement.path/name/mimeType`; 스프레드시트 기반의 인라인 첨부파일 제공 `event.node.refId/label`호스트는 자산 UUID를 권한 확인된 콘텐츠 엔드포인트로 해결하고 공유를 열어줍니다. `DocumentFilePreview`기존 액세스 플래그와 함께 읽기 전용/기록/휴지 모드에서도 동일하게 작동합니다. 서식 있는 텍스트는 첫 번째 편집 모드 클릭 시 첨부 파일을 선택하고 다음 클릭이나 미리보기 버튼을 통해 미리보기를 표시합니다. 읽기 전용 모드에서는 첫 번째 클릭 시 미리보기를 표시합니다. 스프레드시트의 경우는 네이티브 첨부 파일 라벨을 클릭하여 미리보기를 표시합니다. 기존의 전체 세포 객체 렌더러는 계속 사용할 수 있습니다. 미리보기는 모델, 공동 작업 세션 또는 저장된 형식을 변경하지 않습니다.

설치된 서식 있는 텍스트, 마크다운, 스프레드시트, 슬라이드 패키지는 현재의 이미지 미리보기 콜백을 제공합니다. Doca는 이러한 콜백들을 캔버스 리소스과 결합하여 하나의 허가된 이미지 갤러리를 만들었습니다. 호스트는 각 이미지의 고정 ID를 보존하므로, 하나의 자산을 반복 사용해도 별도의 항목으로 유지됩니다. 슬라이드는 페이지/요소 순서를 따르고, 스프레드시트는 공개된 방식으로 작동합니다. `getImageGallery()` 네이티브 셀 초안 및 기타 시트를 포함한 스냅샷입니다. 생성된 다이어그램/Mermaid SVG 프리뷰는 일반 이미지 자산과 함께 느리게 처리됩니다. 라이트박스는 드래그, 이전/다음 컨트롤, 화살표 키, 가로 휠, 터치 제스처를 지원하며, 이미지를 변경할 때는 스크롤을 재설정할 수 있습니다. 활성, 읽기, 역사 및 휴지면은 기존의 권한 플래그를 유지합니다. 갤러리를 열거나 이동하거나 닫는 행위는 초안을 생성하거나 협업 콘텐츠를 작성하지 않습니다.

find/replace는 편집기 모델이나 네이티브 기능을 사용합니다. 서식 있는 텍스트는 호스트 Slate 어댑터를 사용하며, 다른 형식들은 설치된 패키지 find/replace나 네이티브 패널을 사용합니다. 읽기 전용, 연결되지 않은, 프레젠테이션 모드에서는 내용 교체가 불가능합니다. 일반적인 공개 arbitrary-editor 변형 핸들이나 형식 간 동일한 텍스트 범위/정규표현식의 보장도 없습니다.

## 이슈 트래커 패키지 통합 — 2026-10-23

모든 다섯 가지 편집기들은 정확한 공식 npm 버전을 사용합니다. 설치된 Canvas 0.5.14, Sheet 0.2.11 및 Slate 0.4.25 파일은 공개 아카이브와 일치하며, Canvas는 이전에 승인된 C1 바이트와 일치합니다. Slate 0.4.25에는 이전의 DOCX 패치가 포함되어 있고, Markdown 0.4.4에는 이전의 KaTeX/lazy-PDF 패치가 포함되어 있습니다. 구식 편집기 패치는 제거되었으며, 그 소스는 Git 역사에서 복구할 수 있고 로컬 아티팩트도 보존됩니다. 배포 및 릴리스 검사에서는 로컬 편집기 아카이브와 활성 편집기 패치가 거부됩니다. 패키지 감사 및 버전별 브라우저 결과는 기록됩니다. [npm 통합 검증](verification/issue-tracker-2026-10-21/npm-direct.md)0.2.11 스템에는 실제 제어된 뷰 API와 승인된 치수가 추가되었습니다. 73개의 설치 파일은 공식 아카이브와 일치하며, 최종 호스트 웹사이트의 승인은 이전의 0.2.10 결과와는 별도로 기록됩니다.

캔버스는 통제된 상태로 공개됩니다 `viewPreferences` / `onViewPreferencesChange` 그리고 `creationPreferences` / `onCreationPreferencesChange`또한 순수 검증자들도 포함됨 `@smartdoca/canvas/preferences`사용자는 출처, 계정, 문서를 기준으로 한 독립적인 버전-1 브라우저 기록을 승인했습니다. Doca는 명시적인 네이티브 선호 설정 변경만을 처리합니다. 누락된 기록은 기존 동작을 유지하며, 알 수 없거나 잘못된 기록은 보존되며 삭제되거나 덮어쓰지 않습니다. 저장 장애가 발생하면 명시적인 선택이 현재 마운트된 화면에 그대로 유지되고, 저장할 수 없다는 보고가 이루어집니다. 화면 선택 및 명시적인 생성 기본 설정은 기존 요소, API/AI 삽입, 임포트, 협업 데이터 또는 역사 정보를 결코 재작성하지 않습니다. 기본 설정은 이후의 상호작용적 생성에만 영향을 미칩니다. 기존 모듈 수준 세션 스타일 캐시는 브라우저 저장소가 아니며 선호 설정 기록으로 전환되지도 않습니다. 롤백 과정에서는 이러한 기록을 처리하지 않으면서도 그와 모든 후속 콘텐츠를 보존합니다.

캔버스 0.5.14는 메뉴/프로젝션/레이아웃/제목 기능과 기본 키보드 소유권 수정 기능을 유지하며, 실제 객체 핸들 및 명시적 도구와의 상호작용에 초점을 맞춥니다. 자동 도구 완성 기능은 사용자 요청된 초점과는 별개로 유지됩니다; 공개 컴포넌트/핸들 모양은 변경되지 않습니다. 시트 0.2.10은 클립보드/드롭다운 수정 기능과 하이퍼링크 입력 초점, 갤러리 처리 중 지연된 유효성 검사 작업을 수정합니다. 시트 0.2.11은 0.2.10과 비교하여 모델/Yjs 런타임의 승인된 기본 크기만 변경되며, XLSX 런타임은 바이트 수준으로 동일하게 유지되고 스키마 6도 변경되지 않습니다. 일반 셀, 텍스트 초안, 공식, 대화상자 및 읽기 전용 기능은 기본 동작을 유지합니다. PNG는 SVG 전용 폰트 이동 기능에 대한 경고를 생략하며, Doca는 유지된 SVG 경고를 번역합니다. 기존 승인된 다이어그램 표시 규칙, 역사적 리더, 정규화 및 정확한 스키마 검사는 기존 경로를 유지합니다. 편집기 형식 변환, DDL, 기준값, 에포크 또는 대기 중인 업데이트 리팩토링은 도입되지 않습니다. 롤백을 위해 이전의 배포, 매니페스트, 잠금파일, 아티팩트 및 이후의 문서/채팅/파일 작성 기능을 유지합니다.

## 스프레드시트 크기와 개인용 줌 — 2026-10-23

Sheet 0.2.11 수출 `SpreadsheetViewPreferences`, `isSpreadsheetViewPreferences` 그리고 선택적 `viewPreferences` / `onViewPreferencesChange` props; 순수 검증기도 사용할 수 있습니다. `@smartdoca/sheet/preferences`호스트가 저장합니다. `{version:1,zoomRatio}` 아래에 `doca.sheet.zoom.v1:<account>:<document>` 현재의 기본값으로. 기본값은 100%로 유지되며, 명시적인 네이티브 확대/축소 변경만 기록에 저장됩니다. 누락된 기록은 100%를 사용하고, 익명 뷰는 일시적이며, 잘못된/알 수 없는/추가 필드 기록은 보존되지만 거부됩니다. 저장 제한은 피드백과 함께 현재 뷰에서 명시적인 선택을 유지합니다. 확대/축소는 스냅샷, XLSX 콘텐츠, 협업, 취소 및 역사 기능 외에는 적용되지 않습니다.

사용자는 기본적인 크기 설정이 기록되지 않은 새로운 워크시트와 역사적 추가/복구 워크시트에 대해 기본 행 높이 21.78과 열 너비 87.12를 명시적으로 승인했습니다. 명시적인 기준 크기, 수동으로 설정한 행/열 크기, 원래의 기준/시드/체크포인트/업데이트 바이트는 그대로 유지됩니다. 열기 작업은 필드를 백필링하거나 데이터를 이동시키지 않습니다. 패키지를 되돌리면 이전에 누락된 필드의 표시 기본 설정이 복원되며, 호스트를 되돌리면 독립적인 확대 기록을 사용하지 않고 이를 보존하며 이후의 콘텐츠 편집도 유지됩니다.

## 원시 이벤트 소유권, 코멘트 및 간단한 메모 — 2026-10-22

네이티브 명령이 실행되기 전에, 호스트 컴포지터나 외부 편집 가능 타겟이 소유한 키보드/클립보드 이벤트는 문서 패키지가 거부해야 합니다. 호스트 React 프로파일링 가드만으로는 패키지 수준의 키보드 디스패처를 보호할 수 없습니다. 캔버스 0.5.12는 공개 프로퍼티, 저장된 시네 맵 필드 또는 명령 스키마를 변경하지 않고 이러한 소유권을 강제합니다. Doca는 코멘트 입력, 로딩/업로드 피드백, 초안 보관, 레이아웃 및 승인된 마커 페이징을 소유합니다. 코멘트를 입력하거나 삭제하거나 붙이거나 취소하는 동안 편집기 요소를 선택된 상태로 유지하면 문서 체크포인트와 순서가 변경되지 않아야 합니다. 영구적인 앵커 형식, 존재 여부 및 문서 아웃박스는 변경되지 않습니다.

사용자가 승인한 확장 기능의 간단한 설명에는 기존의 서식 있는 텍스트나 마크다운에만 적용되는 활성화된 권한이 부여된 추가 프로필 대상이 명시적으로 선택되며, AI 없이 일반 텍스트가 추가됩니다. 해당 대상, 텍스트 및 티켓은 현재 확장 기능 보기에서만 존재합니다. 호스트는 기존의 네이티브 콘텐츠 명령, 영수증 및 공동 작업 전송 기능을 사용하며, 임의의 문서 접근 권한을 부여하거나 편집기 자동 저장 채널을 추가하지 않습니다. 서식 있는 텍스트는 문자 그대로의 단락을 추가하고, 마크다운은 현재 렌더러를 통해 제공된 일반 소스 텍스트를 추가합니다. 불확실한 응답은 동일한 티켓/요청 ID를 다시 시도하며, 새로 준비된 대상은 없습니다. 티켓은 5분 동안 프로세스 로컬 상태로 유지되며, 재시작/기간 만료/철회는 입력 내용을 유지한 상태로 시도를 중단시킬 수 있습니다. 자세한 내용은...을 참조하십시오. 시트 0.2.17이 공개됨 `SpreadsheetEditor.currentUserId?: string | null`도카는 인증된 사용자 UUID를 제공합니다; 네이티브 `type: 'user'` 원자 노드가 일치함 `refId` 정확합니다. 일치하는 언급은 흰색 텍스트가 있는 캡슐 모양의 둥근 파란색 배경을 만듭니다. 다른 사용자 언급은 파란색 텍스트를 만듭니다. 모든 사용자 언급은 밑줄을 생략합니다. 그리드, 포뮬러 바, 셀 드래프트 캔버스 렌더링은 읽기 전용을 포함하여 동일한 규칙을 사용합니다. 다른 하이퍼링크는 그 원본 스타일을 유지합니다. 전체 셀 호스트 언급 객체는 공유된 스타일을 계속 사용합니다. `UserMention` 렌더러.

아이덴티티가 변경되거나 지우면 기존의 실행 환경만 다시 그려집니다. 아이덴티티와 그에 따른 색상은 셀, 취소, 클립보드, XLSX, 협업 또는 기록에 저장되지 않습니다. 커스텀 실행 환경은 선택적 옵션을 받습니다. `RuntimeFactoryContext.userMentions.currentUserId()` getter와 may를 구현할 수 있습니다. `SpreadsheetRuntime.refreshUserMentions()`이것들은 저장 형식이나 오래된 API 어댑터가 아닌 뷰 기능입니다. 네이티브 사용자 노드 데이터와 스키마 6은 변경되지 않았습니다. 8개의 모델/Yjs/XLSX/preferences JS 엔트리포인트는 0.2.15와 바이트 단위로 동일합니다. 역사적 리더와 승인된 기본 설정은 이 변경 사항의 적용 대상에서 제외됩니다. 자세한 내용은 참조하세요. [변경 사항 검증](../specs/004-sheet-self-mentions/validation.md) 현지 검증 및 게시 범위를 위한 것.

## 스프레드시트 셀-드래프트 기록 단축키 — 2026-11-20

도카가 공식 npm을 핀합니다. `@smartdoca/sheet` 0.2.19. 기본 셀 편집기는 Focus 기능을 지원하지만, Cmd/Ctrl+Z는 텍스트 초안을 취소하고, Cmd/Ctrl+Y 또는 Cmd/Ctrl+Shift+Z는 다시 실행합니다. 초안이 커밋된 후에는 시트의 취소 및 재실행 기능이 기존의 협업 기록을 따라 계속됩니다. 다른 호스트의 입력은 이러한 편집기 단축키를 사용할 수 없습니다.

## 스프레드시트 자동 높이 측정 보호 장치 — 2026-11-23

도카가 공식 npm을 핀합니다. `@smartdoca/sheet` 0.2.20. 단일의 쇠약한 텍스트 셀이며, 문서 구조가 페이지를 생성하지 않는 정렬된 목록 형태의 단락으로 인해 고정된 엔진의 자동 높이 측정 기능이 작동하지 않게 되었습니다. 시트 열 너비 명령어는 너비 변경 전의 고정 열 너비를 측정하므로, 이러한 셀은 사용자의 열 크기 조정 기능을 무시하게 만들었으며(실시간 워크북의 첫 번째 열에서 보고되었습니다), 이와 같은 충돌로 인해 첫 번째 페인팅 작업과 다른 열의 크기 조정에 대한 자동 높이 계산 기능도 작동하지 않게 되었습니다. 이 패키지는 단일 측정 값을 보호합니다.`SpreadsheetSkeleton.calculateAutoHeightForCell`): 실패한 측정 결과는 각 호출자의 기본 설정으로 돌아가므로 크기 조정이 적용되고 렌더링이 계속됩니다. 로컬 명령과 관련된 처리되지 않은 거부 사항은 메시지당 한 번씩 경고 툴팁 형태로 콘솔에 전체 스택 정보와 함께 보고됩니다.

변경되는 것은 오직 실패 경로뿐입니다: 공개 API, 선언 수출 세트, CSS, 스키마, 기준값, 에포크, 체크포인트 또는 호스트 저장 채널은 변경되지 않습니다. 모델/Yjs/XLSX/선택사항 런타임 JavaScript 및 index.css는 0.2.19와 바이트 단위로 동일합니다. 롤백을 위해 이전 패키지 핀과 락파일을 유지합니다.
