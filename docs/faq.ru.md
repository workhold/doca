<a id="is-there-a-default-administrator-password"></a>

## Есть ли стандартный пароль администратора?

Нет. Убегай. `bash scripts/bootstrap-admin.sh` После того, как контейнер находится в здоровом состоянии. Пароли должны содержать как минимум 12 символов. Для существующего аккаунта используйте `bash scripts/reset-admin-password.sh`Инициализация не является восстановлением пароля.

<a id="why-does-the-browser-not-connect-to-port-39120"></a>

## Почему браузер не подключается к порту 39120?

Compose связывает порт с серверным loopback. Используйте HTTP(S) оригинальный адрес, настроенный… `DOCA_ORIGIN`Получено через настроенный обратный прокси. URL IP-адреса сервера работает только в том случае, если оригинальный адрес и карта портов точно соответствуют ему. Проверьте карту, Host, использование TLS и передачу данных через WebSocket. Смотрите [развертывание](deployment.ru.md).

<a id="which-environment-example-should-i-use"></a>

## Какой пример окружения мне следует использовать?

Для опубликованной Docker-импорта копируйте. `docker.env.example`Для разработки источника копируйте. `.env.example`Настройка `DOCA_ORIGIN`, `DOCA_FILE_STORE_ID`, `DOCA_FILE_STORES_JSON`и необходимая устойчивость `DOCA_CREDENTIAL_MASTER_KEY` Перед началом работы с Compose замените публичный образец ключа при новой установке; оставьте оригинальный ключ для существующей базы данных. Смотрите [конфигурация](configuration.ru.md).

<a id="why-do-i-get-421-403-or-a-disconnected-editor"></a>

## Почему у меня появляются 421, 403 или отключенный редактор?

421 обычно означает, что хост не соответствует настроенному оригинальному источнику. Запросы на мутацию требуют одного и того же оригинала; несоответствие приводит к возврату кода 403. Редактирование также требует авторизации и работающего обновления WebSocket. `/api/v1/ws`Проверьте адрес браузера, настройки прокси, состояние учетной записи и текущие разрешения на ресурсы.

<a id="what-should-i-do-if-startup-rejects-the-database-baseline"></a>

## Что мне делать, если стартап отклоняет базовый уровень базы данных?

Стоп и прочитайте. [Контракт на обновление базы данных](database-schema-evolution.ru.md) и соответствие [требования к выпуску](releases/0.2.38.md)Поддерживаемые поколения получают одобренное структурное приведение; неподдерживаемые поколения — семантические изменения и различия, требующие проверки, препятствуют запуску до постоянных изменений. Сохраняйте старую развертывание, базу данных, файлы и секреты для откатов. Не удаляйте таблицы, не сбрасывайте объем данных или не изменяйте метки базового состояния, чтобы запустить систему.

<a id="how-do-i-inspect-startup-problems"></a>

## Как проверить проблемы при запуске?

```sh
docker compose config --quiet
docker compose ps
docker compose logs --tail=100 doca
curl -fsS -H 'Host: doca.example.com' http://127.0.0.1:39120/health
```

Запустите эти файлы на сервере в контейнере checkout. `compose.yaml`Не публиковать логи, содержащие секреты. Для разработки исходного кода используйте `http://127.0.0.1:39130` и конфигурация разработки.

<a id="are-github-pages-and-the-doca-application-the-same-deployment"></a>

## Являются ли GitHub Pages и приложение Doca одним и тем же развертыванием?

GitHub Pages используется для хранения этого статического веб-сайта с документацией. Приложение Doca требует своего контейнера/сервера, баз данных, постоянных файлов и протокола HTTP(S). Обновление веб-сайта с документацией не влияет на работу приложения Doca или его обновление.

<a id="can-i-update-or-restart-without-deleting-my-files"></a>

## Могу ли я обновить или перезагрузить без удаления файлов?

Обычное `docker compose restart` Сохраняет постоянный том. Изменения конфигурации используются `docker compose up -d`Перед изменением версий изображений прочитайте примечания к выпуску и сделайте копию всех баз данных, файловых хранилищ и защищенных конфигураций. Избегайте `docker compose down -v`, который удаляет том.

<a id="why-is-a-plugin-or-an-external-service-unavailable"></a>

## Почему плагин или внешний сервис недоступны?

Пакеты плагинов должны соответствовать текущему контракту SDK и хранения данных. После установки необходимо вручную перезапустить каждую инстанцию. Плагины, использующие зашифрованные учетные данные, должны иметь одинаковый постоянный главный ключ на каждом реплике. Наличие ИИ, SSO, поиска и возможности хранения данных в облаке также зависит от реальных учетных данных и сетевого подключения; тесты источника не подтверждают пригодность для работы в режиме реального времени. Смотрите. [развёртывание плагина](plugin-deployment.ru.md).

Используйте фактический настроенный хост в команде health выше. Значение 421 указывает на несоответствие хостов, включая случаи проверки loopback. По умолчанию не доверяется никакой прокси; ограничения на IP-адреса прокси требуют строгого настройки. `DOCA_TRUST_PROXY`.
