# 능력과 한계

[中文](features.zh-CN.md)

이 페이지는 현재 소스와 비교하여 확인되었습니다. **0.2.25** 그리고 플러그인 SDK **0.1.11** 2026-10-29에. 비즈니스 플러그인을 설치하기 전에 호스트는 다음과 같은 핵심 기능을 제공합니다. 각 독립적인 플러그인은 자체 기능, 버전 및 수용 결과를 문서화합니다.

<a id="independent-plugins-and-removed-features"></a>

## 독립적인 플러그인과 제거된 기능들

- **간단한 메모** 호스트에서 제거되었습니다. 아무것도 없습니다. `#/notes` 페이지, `/api/v1/quick-notes` API, `quick_notes` 표, 또는 `quick_note_compilations` 표. 이전 가이드는 그대로 유지됩니다. [연구 기록](research.ko.md); 현재 호스트에서는 이 인터페이스를 사용할 수 없습니다. 이 리포지토리는 빠른 노트 플러그인 버전이나 현재 기능 보장을 제공하지 않습니다.
- 이메일, 캘린더, 멤버십, 포인트, 결제, 비즈니스 할당량, 콘텐츠 모니터링은 독립적인 비즈니스 플러그인에 속합니다. 기본 이미지는 이러한 비즈니스 기능을 전혀 제공하지 않습니다. 등록 검토와 보안 감사는 핵심 기능으로 유지됩니다.
- 템플릿, 자료, 자료 컬렉션, 그리고 플러그인 문서 요소에는 호스트 인터페이스와 픽터가 있습니다. **제로 기본 제공자**SDK와 호환되는 제공자를 별도로 설치해야 합니다. 이전의 호스트 템플릿 관리 CRUD 페이지는 없습니다. 제공자 없이도 빈 문서 생성 기능은 사용할 수 있습니다.
- [예시](../examples) 지원 개발 및 격리된 수용. 기본 이미지는 이들을 설치하지 않으며, 그 결과는 독립적인 비즈니스 플러그인을 검증하지 못합니다.

<a id="unavailable-or-requiring-separate-verification"></a>

## 사용 불가하거나 별도의 확인이 필요함

- 편집자에는 지속적인 로컬 복제본과 인식되지 않은 업데이트 큐가 있으며, 이를 위해 사용 가능한 권한이 부여된 복제본과 성공적인 브라우저 저장이 필요합니다. 이는 완전한 오프라인 애플리케이션이나 오프라인 콜드 스타트 보장이 아닙니다. OIDC 제공자인 Doca와 SAML은 사용할 수 없습니다. 자세한 내용은 참조하세요. [협력](collaboration.ko.md).
- 플러그인의 임시 작업 공간, 클러스터 전체에 걸친 비즈니스 작업 소진, 임의적인 SQL, 그리고 분산형 크로스서비스 트랜잭션이 사용 불가능합니다. 타겟 SDK 계약은 기존의 내보내기를 정의하지 않습니다; 참조하세요. [실행 상태](plugin-sdk-contract.ko.md).
- 네이티브 플러그인 웹뷰 컨테이너는 소스 프로토콜을 가지고 있습니다. iOS/Android 빌드, 기기 동작, 그리고 독립적인 플러그인 통합은 각각 별도의 인정이 필요합니다. 서버 설치에서는 네이티브 자바스크립트를 다운로드하거나 실행하지 않습니다.
- 실제 AI, SSO, 인증 게이트웨이, 웹호크, S3/CDN 및 기타 서비스는 배포 설정에 의존합니다. 과거 릴리스 테스트는 각각 정해진 범위를 가지고 있으며, 모든 외부 서비스나 장치를 검증하지는 않습니다.
