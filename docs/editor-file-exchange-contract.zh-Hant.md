# 檔案交換接入約定

[English](editor-file-exchange-contract.md)

適用 Doca 各編輯器的檔案匯入、匯出和包升級。基礎內容與可接受的樣式優先，不要求完整 Office 還原；部分能力有損可以接受，但不能靜默丟棄重要內容。這裡規定職責與驗收，不意味著每個包已實現全部介面。

<a id="职责"></a>

## 職責

- 子包負責格式識別、解析/序列化、模型轉換、素材列舉、結構化警告/錯誤、檔案大小和解壓/圖片尺寸限制。以獨立入口暴露純轉換器，宣告 Node 或瀏覽器環境要求。
- 平臺負責選擇檔案、建立新文件、授權上傳和下載、使用者反饋、檔名及觸發瀏覽器下載。包不得自行連線平臺 API、建立業務文件或開啟第二條儲存鏈路。
- 匯入結果應為本機模型、待上傳素材及警告。匯出結果應為 Blob、檔名、MIME 及警告。具體欄位以實際版本型別為準，不強制假定統一方法名。
- 支援型別由真實交付能力決定，檔案字尾 accept 只用於提示，解析仍需驗證檔案內容。使用者介面不提供 JSON 上傳下載；內部模型及故障恢復副本不等於便攜格式。

<a id="协同、素材与安全"></a>
<a id="协同素材与安全"></a>

## 協同、素材與安全

- 預設匯入建立新資源、新 epoch 和穩定身份；不將匯入結果覆蓋正在編輯的 Y.Doc，不復用舊評論、許可權、歷史和 outbox。全文替換必須另走明確的替換協議。
- 需要所屬資源才能上傳時，可先建立新記錄、上傳素材，再執行一次性初始化；服務端必須拒絕已初始化/已開啟/已修改資源，不能讓這個介面成為繞過協同的全量儲存通道。
- 素材重新上傳獲得新文件自己的穩定 ID。不能持久化 blob/data/臨時簽名地址，也不能從匯入檔案信任已有使用者、資源或許可權 ID。外部資源預設不自動抓取；若支援抓取，宿主另行實現 SSRF/大小/來源限制。
- SVG 等主動內容必須安全處理。Doca 當前將已由畫板包清洗的 SVG 柵格化後走原有圖片上傳服務；不直接放開同源任意 SVG 執行。
- 業務歷史採用協同契約中的保留規則；淘汰歷史行不代表素材已無引用，不據此直接刪除附件。檔案匯出讀取當前文件或仍保留的指定歷史；已淘汰的版本明確返回不存在，不回退到當前內容冒充歷史。
- 匯出讀取受當前資源許可權約束；檔案轉換不改變正文、選區、撤銷、presence 或儲存狀態，不等待/偽造 ACK。若包要求先結束原生編輯，宿主明確完成編輯後呼叫，不把 flush 隱藏在純匯出中。
- 取消、失敗及遲到回撥不得插入到其他文件/選區。服務端二次校驗許可權；中斷上傳不代表服務端資產已回滾，應說明臨時資源清理策略。

## 按線上樣式匯出 PDF 與可編輯匯入

富文字匯出將當前本機模型的副本放入只讀 portal，保留宿主語言、外掛及文件上下文；不接入協同、不替換原編輯器、不結束當前編輯、不寫 checkpoint。Markdown 掛載子包預覽並使用編輯器相同的字型樣式。兩者等待圖片、公式和圖表，複製計算樣式，內嵌經授權讀取的平臺圖片和字型，移除編輯控制元件，再向 `POST /api/v1/resources/:id/pdf` 提交自包含頁面。音影片保留可讀說明和受許可權約束的下載連結，附件及提及標籤保留可讀內容。PDF 文字仍可選擇。紙張寬度沿用文件實際寬度，寬高比為 √2，上下列印邊距 24 px；分頁與連續線上頁面可能不同。

宿主使用固定 WeasyPrint 70.0 的獨立 Python 程序，不執行指令碼，僅允許內嵌 data 資源；網路與宿主檔案讀取被拒絕，圖片資源缺失或損壞時匯出失敗。渲染完成後仍二次檢查 `read_content`，保留只讀/公開許可權規則、32 MiB 輸入、兩個併發任務、60 秒期限。AI 畫板複用已安裝 Canvas SDK 的 SVG 匯出，在宿主適配的隔離 Node DOM 中用原生 Canvas 測量文字，再用 resvg 與隨包中文字型生成圖片；這是宿主適配，不表示編輯器包新增了 Node API。PDF.js 讀取/匯入、LibreOffice 轉換保持獨立。重新構建的 Docker 執行時使用 `node`，包含 Python/Pango/中文字型，不含瀏覽器，不依賴宿主 seccomp 檔案。舊 `DOCA_PDF_CHROMIUM` 被明確拒絕，原始碼安裝透過 `DOCA_PDF_PYTHON` 指定固定 Python 環境。SDK 已有歷史讀取規則保留原路徑，不做資料庫/文件轉換或瀏覽器回退；回滾恢復原始碼、鎖檔案和映象，保留部署配置及後續資料。 含 HTML 標籤的流程圖以 PNG 保留瀏覽器佈局，普通正文文字仍可選擇；中文字型使用 TTF，避免逐任務解碼 WOFF2。匯出時不把 colgroup 的計算總寬誤作為各列最小寬。

PDF 匯入優先生成可編輯內容。已交付 Markdown 解析器繼續校驗檔案、頁數、圖片限制，並提取素材與警告；宿主 PDF.js 適配補充字號、基礎字型、粗斜體、文字顏色、安全連結、按字號識別的標題層級、簡單列表、規則列距表格及按頁面位置排列的圖片。富文字直接使用該本機模型，Markdown 使用其便攜序列化結果。素材重新繫結和新文件一次性初始化仍是儲存邊界。背景色、下劃線、向量圖、複雜分欄/表格和公式重建可能簡化；掃描頁保留為圖片，不進行 OCR；原解析器警告繼續展示。本次不改變持久化模型、schema、舊格式轉換或遷移規則。

Slate 0.4.25 已將原宿主 DOCX 補丁正式釋出到 ESM/CJS 轉換入口：Word 直接字型、字號、顏色、背景、段落對齊、顯式關閉 marks 和單元格文字格式，以及線上標題字號、1.6 行距和 A4 預設值。任意繼承樣式、複雜分節和精確分頁仍不在驗證範圍。Markdown 0.4.4 已正式包含原 KaTeX/延遲 PDF 載入修復。Doca 直接安裝這兩個正式包，無編輯器補丁繫結。歷史補丁可從上一版 Git 原始碼恢復；移除它們不轉換已存文件或改變協作格式。

驗收：`tests/document-pdf.test.ts` 覆蓋真實 WeasyPrint PDF、可選擇中文、本機 PDF 重建、真實 DOCX XML/重匯入以及指令碼/遠端圖片阻斷；`tests/document-pdf-access.test.ts` 覆蓋只讀許可權、撤銷和正文 checkpoint 不變。`node --import tsx scripts/qa-document-pdf.mts` 使用隔離瀏覽器樣本，驗證上下文保留、Y.Doc 零更新、圖片匯出後重匯入、Mermaid/公式及三頁長表格，視覺產物寫入 `artifacts/verification/document-pdf/`。使用 Poppler 將 PDF 渲染為圖片，與線上截圖對照；不開啟使用者文件或生產資料庫。

<a id="验收证据"></a>

## 驗收證據

剪貼簿也遵守同一資源邊界：包只報告檔案/文字和捕獲的目標位置；宿主上傳圖片或附件、判斷本站連結並做許可權查詢，包再用正常編輯事務插入。非同步完成時不得采用新的當前選區，也不能寫入已關閉或失去編輯許可權的文件。普通表格多行/製表符貼上保留原生行為。超連結只允許安全協議；站內文件儲存穩定 ID 並生成相對地址，不存域名。Excel 當前業務物件為整單元格物件，不應宣傳為支援混合行內富文字；XLSX 往返可能降級為可讀標籤並給出警告。

使用隔離資料和實際檔案，至少覆蓋：基礎中文/格式/表格或圖形；匯入後編輯並過載；匯出檔案重新開啟或匯入；不同編輯例項同步；匯出前後零正文增量；只讀匯出與編輯禁用；損壞檔案/超限/取消；素材重新繫結和無許可權讀取；警告可見。逐項記錄透過、降級及未驗收範圍，構建成功不等於匯入匯出正確。

## 三編輯器升級 — 2026-10-17

Doca 固定安裝實際 npm 包 `@smartdoca/slate` 0.4.22、`@smartdoca/slides` 0.3.0-alpha.3。Canvas 使用不可變的 `vendor/smartdoca-canvas-0.5.0-75e637df1a75.tgz`：npm 0.5.0 的庫構建誤刪了 Slate 與純文字內部編輯器註冊模組，AidCanvas 原始碼已透過 sideEffects 宣告修復，宿主使用重建產物。這個修復包和原始碼改動尚未釋出 npm。

Slate 新增五頁元素配色，進入圖形標籤編輯時全選文字。codec/Yjs/headless 位元組與 0.4.20 一致，原有 DOCX 補丁原樣繫結到 0.4.22。Canvas 保持 `aidcanvas-yjs` schema 1；圖片和附件回撥儲存穩定資產 ID，傳遞真實進度和取消訊號，並接入宿主鑑權預覽，包括歷史、回收站、審計只讀檢視。服務端校驗新增富文字媒體引用屬於當前文件。臨時畫布 presence 完整轉發經過校驗的相對文字位置和場景滑鼠座標，身份及顏色仍由服務端決定；支援僅滑鼠訊息，不復用永久評論錨點。

Slides 要求 codec revision 6。客戶端與服務端統一嚴格協商 `eppt-yjs-v6`，文件 schema 2 / protocol 1 不變。使用者明確選擇**只支援新文稿**：舊 `eppt-yjs-v5` 文稿和舊客戶端拒絕開啟或接入，原 checkpoint、增量、epoch、歷史和待提交訊息標識原樣保留。不增加舊 codec 讀取、編碼標識改寫、自動轉換、遷移或 SQL 結構變更。宿主接受原生文字邊距與表格欄位；AI 表格命令透過原生 controller 支援合併/拆分、樣式、尺寸、清空、貼上與批次刪行列。單元格仍是純文字加整格樣式。

部署時服務端與 Web 必須同步更新。保留舊部署、版本鎖定、補丁、鎖檔案與安裝產物；舊程式不承諾讀取新功能寫入，恢復前須保留後續資料。本次沒有修改使用者資料庫或部署。隔離驗收、雜湊、截圖和邊界見 `docs/verification/three-editor-upgrade-2026-10-17/`。
