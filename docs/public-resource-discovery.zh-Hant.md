# 公開資源、發現與收錄

[English](public-resource-discovery.md)

<a id="管理员策略"></a>

## 管理員策略

管理員在「許可權與可見性 → 內容許可權 → 公共發現」分別設定文件、知識庫、資料夾：

| 模式 | 發現目錄 | 未收錄全文搜尋 | 主動收錄後的個人搜尋 |
| --- | --- | --- | --- |
| 僅連結訪問 | 不展示 | 不參與 | 參與 |
| 可發現，收錄後搜尋 | 展示、按標題查詢 | 不參與 | 參與 |
| 全站可發現、可搜尋 | 展示、按標題查詢 | 參與 | 參與 |

策略隻影響已公開資源的分發，不會使私有資源自動公開。三類都設為僅連結訪問時，仍保留公共資源入口及“瀏覽過”“已收錄”，隱藏“發現”Tab。介面不返回不可發現的資源。

歷史分發配置在未儲存新策略前按原配置解釋；儲存時寫入三類獨立的 `publicModes`。保留歷史設定與收錄資料，不刪除訪問記錄。

<a id="个人范围"></a>

## 個人範圍

瀏覽只寫訪問記錄，不再自動收錄。舊 `source=opened` 的自動加入記錄不提供收錄搜尋資格，也不出現在收錄清單。主動授權、已接受邀請、所有權繼續按現有規則參與。

三類資源統一使用獨立的 `resource_collections` 表，按使用者、資源型別、資源 ID 去重。公開目錄不排除自己擁有或已獲授權的公開資源；點選收錄就加入清單，不按原有授權關係過濾。

搜尋候選為原有範圍、收藏與收錄清單的並集，返回結果仍復核當前訪問許可權。取消收錄只移出清單，不影響成員、邀請和原有訪問權。

當前結構建立空收錄表，啟動不會複製歷史條目；已有收錄行保留。自動加入、邀請和訪問記錄不視為收錄。



搜尋可切換全部可搜尋資源、我的範圍、全站公開正文。全站正文僅包含管理員允許全站搜尋的資源；發現目錄的標題查詢不呼叫正文搜尋或向量檢索。普通檔案搜尋及 AI 檔案檢索同樣檢查容器收錄與公開搜尋策略。

<a id="容器规则"></a>

## 容器規則

收錄知識庫或資料夾包含現有和以後新增的可訪問內容，查詢時動態判斷，不復製成員記錄到每個子項。

公開知識庫統一其頁面的閱讀範圍，即使頁面關閉協作者繼承也不能關閉公開閱讀。頁面仍可配置編輯、評論和管理類許可權。點查許可權與列表 SQL 使用相同的公開閱讀繼承規則。知識庫中的頁面使用知識庫型別的發現與搜尋策略，獨立文件使用文件型別策略。

資料夾公開狀態儲存在 `folder_publications`，允許站內登入使用者閱讀其中現有和新增內容；不授予管理許可權。當前檔案管理與下載介面要求登入，不提供匿名檔案訪問。公開關閉後，仍須依照當前成員許可權判斷訪問，收錄本身不授予許可權。

頁面許可權面板顯示公開知識庫來源；資料夾分享面板說明公開範圍包含現有和新增內容。移入公開容器的內容隨容器公開，移出按新位置許可權計算。

<a id="发现界面"></a>

## 發現介面

統一公共資源頁包含“瀏覽過”“發現”“已收錄”，按文件、知識庫、資料夾篩選。“瀏覽過”包含訪問過且當前仍可訪問的僅連結公開資源；瀏覽歷史不產生搜尋資格。各業務列表不再設定“公開資源”快捷入口。

獨立主頁 `/home` 彙總文件、知識庫、資料夾和檔案的最近訪問、待處理工單與知識庫人工裁決。文件頁移至 `/documents`，繼續保留最近瀏覽，並提供歸我所有、與我協作、我的收藏、我的收錄。共享資料夾無收藏，提供全部、我共享的、共享給我的、已收錄。

公開列表統一提供收錄和取消收錄。文件行的更多選單包含收錄、取消收錄及有權執行的刪除；收藏與置頂保持快捷操作。資源詳情不另增收錄入口。

主頁統計使用當前使用者可訪問的資料。工單複用 onlyMine 審批/接受步驟；人工裁決複用知識庫維護許可權與待辦校準邏輯，處理後從主頁移除，來源失敗單獨展示，不冒充零待辦。首版接入內建來源，尚未新增對外外掛主頁 SDK。

文件與知識庫沿用 resource_visits，檔案和資料夾記錄到 workspace_activity。讀取最近訪問時重新鑑權，按時間合併分頁；預覽檔案才記錄訪問，列表縮圖不算瀏覽。

第一階段提供標題查詢、更新時間倒序、穩定分頁、主動收錄與批次取消收錄。知識庫以容器展示，不平鋪其頁面。使用資料庫目錄查詢，不新增 Meilisearch 依賴，也不提供個性化推薦流。
