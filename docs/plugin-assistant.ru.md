# Запустите помощника ИИ из плагина.

[中文](plugin-assistant.zh-CN.md)

Источник SDK 0.1.7 был представлен. `PluginWebHost.ai.open(input)`Веб-интерфейс открывает полноценного персонального помощника; приложение-плагин WebView открывает нативный диалог. Проверка источника не подтверждает публикацию в npm или обновленное приложение. Это API запуска клиента; серверная обработка в фоновом режиме имеет отдельный контракт.

```ts
import type { PluginAssistantOpenInput } from "@smartdoca/plugin-sdk/web";

const input: PluginAssistantOpenInput = {
  prompt: "Summarize this email and list action items",
  context: mail.plainText,
  documentIds: [document.id],
  attachmentFileIds: [attachment.fileId],
};
const { sessionId } = await host.ai.open(input);
```

| Параметр | Поведение и ограничения |
| --- | --- |
| `prompt` | Можно изменять начальный текст ввода |
| `context` | Простой текст, добавленный после `prompt`Максимальное количество символов – 20,000, это сообщение пользователя, а не системный приказ. |
| `documentIds` | Максимум 20 различных UUID документов хоста; хост читает в настоящее время разрешенные названия/форматы и отображает ссылочные чипы. |
| `attachmentFileIds` | Максимум 8 уникальных UUID файлов хоста, максимум 20 МБ каждый и 25 МБ в общей сложности; копируется через авторизованные API в приложения для AI. |
| `sessionId` | УUID существующей переписки, принадлежащей текущему пользователю; пропуск этой информации приводит к созданию новой переписки; архивированные переписки необходимо сначала восстановить. |
| `modelId` | Доступная модель; при отсутствии используется модель диалога, параметры пользователя, затем параметры сайта |
| `autoSend` | Подготовка по умолчанию; явная `true` Предоставляет сообщение и требует непустого текста `prompt` или `context` |

`host.ai.open()` Можно начать пустое сообщение. Оно возвращается. `Promise<{sessionId: string; jobId?: string}>`. `jobId` Это происходит только тогда, когда непосредственное отправление запроса выполняется; это не означает, что модель завершила свою работу. Одновременные повторные запуски в одном клиенте отклоняются. Каждый успешный новый запрос является отдельным запуском и не автоматически повторяет отправку сообщения.

```ts
const { sessionId, jobId } = await host.ai.open({
  prompt: "Draft a reply",
  context: mail.plainText,
  autoSend: true,
});
```

Ссылки, файлы, конверсии, модели и отправка всего этого требуют разрешения текущего хоста. Идентификация происходит из сессии. Входные данные не могут обеспечить `userId`токены или системные запросы. Неизвестные поля, дублирующие ID, некорректные UUID и чрезмерные входные данные отклоняются. Плагины должны убедиться, что их бизнес-контент может быть передан тому пользователю и ИИ. Запуск не расширяет полномочия ресурсов или обходит политику выполнения моделей, одобрение инструментов или регистрацию использования.

Отказ в разрешениях, недоступные модели, архивированные/диалоги с другими пользователями, ограничения на прикрепления, сетевые ошибки и переключение учетных записей отклоняют запрос. Прикрепления, которые все еще обрабатываются, могут быть предварительно заполнены; немедленная отправка сообщений сообщает о явной ошибке. Плагин может повторно попытаться или открыть предварительно заполненный диалог. При неудаче не удаляются данные пользователя; созданные обычные прикрепления или пустые диалоги подчиняются существующим правилам удержания хоста.

Предзаполнение существует только в памяти текущего UI-процесса и теряется при обновлении/выходе. URL содержат только идентификатор диалога и внутренний идентификатор однократного запуска приложения, без параметров текста или приложений. Нативный `assistant.open` Используется пространство имён плагина и фиксированные учётные данные. Отключение плагина или смена учётных записей отменяет ожидающие запросы; учётные данные никогда не попадают в WebView. Ссылки и приложения могут быть удалены перед отправкой в Web и App.

Этот инкремент не вносит никаких изменений в схему базы данных, старый формат читателя, процесс миграции или адаптер для старого хоста. Существующие диалоги сохраняют обычный формат хоста; для возврата источника не требуется никаких преобразований или удалений. Хост, не имеющий этой функции, или нативный контейнер, не имеющий… `assistant.open`Не можно предоставить этот функционал. Необходимо развернуть соответствующие артефакты; независимая публикация через npm и прием устройств требуют отдельной проверки.
