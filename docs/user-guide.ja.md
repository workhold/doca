<a id="documents-and-libraries"></a>

## 文書と図書館

作成メニューを使ってリッチテキスト、Markdown、スプレッドシート、スライド、キャンバス文書を作成します。個人文書は独立したページです。ライブラリには目次が含まれ、ネストされた文書ページも含むことができます。新しい文書は登録されたテンプレートを使用できます。 [テンプレートと資料](creation-resources.ja.md) ソース選択と検索の説明。

エディターを通じて画像や添付ファイルを挿入します。クラウド保存の状態はサーバーの永続性確認結果を示します。ローカルレプリカや確認されていない更新は、ブラウザのストレージが成功した場合にのみ保持されます。これは完全なオフラインアプリケーションやオフラインでのクールスタートを保証するものではありません。ストレージが失敗したり、機能がサポートされていない場合は、表示される状態に従ってください。 [共同編集](collaboration.ja.md).

ドキュメントメニューでは、あなたの許可に応じて共有、コピー、移動、履歴、ゴミアイテムなどの操作が可能です。コピーされたものには独立したIDが付与されます。移動操作では継承や公開範囲が変更されるため、宛先を確認してください。 [文書と共有](document-experience.ja.md) そして [権限](permission-inheritance.ja.md) ルールを説明してください。

<a id="sharing-and-discovery"></a>

## 共有と発見

リソースの閲覧範囲を設定したり、名前のある共同作業者を招待したり、共有リンクを作成したりします。閲覧、コメント、編集、管理はそれぞれ異なる役割です。公共図書館はページの閲覧基準を設定します。管理者は自動的にプライベートコンテンツにアクセスできるわけではありません。

公開されている情報、個人コレクション、お気に入りのもの、最近の訪問はそれぞれ異なる目的を持っています。訪問はリソースを収集するものではありません。コレクションはアクセス権を与えるものでもありません。検索は現在の権限を再確認するものです。 [発見と収集](public-resource-discovery.ja.md).

<a id="files-comments-and-notifications"></a>

## ファイル、コメント、通知

狭いウィンドウでは、ファイルマネージャーの列表示がフォルダ内の内容から始まります。ファイルを選択してプレビューし、閉じるボタンを使ってフォルダに戻ります。

通常のファイルには個人用ファイルや共有フォルダを使用しましょう。ダウンロードには承認が必要です。オブジェクトIDは公開されたダウンロードリンクではありません。文書は物理的な保存ディレクトリを公開せずにファイルを参照することができます。詳細は [ファイルストレージ](storage.ja.md).

コメントは、リプライ、メンション、解決、通知をリソースアクセスに応じてサポートします。一時的な共同編集カーソルは、永続的なコメントアンカーとは別物です。 [コメントと通知](comments-and-community.ja.md) 可視性とサポートされる動作を説明する。

コメントを削除すると、確認バブルが表示されます。 **解決されたコメント** コンテンツ・コメントサイドバーの上部にあるアイコンは、解決済みのスレッドと返信を表示します。著者や管理者は、それらを未解決としてマークすることができます。

<a id="knowledge-and-ai"></a>

## 知識とAI

[ナレッジブック](knowledge-books.ja.md) 明示的に承認されたソースや人間のフィードバックを不変のMarkdown文書ツリーに変換します。ページ内または個人用AIアシスタントを通じてワークフローや受け入れ基準を編集できます。ネイティブライブラリやサブスクリプションは依然としてソース管理ツールとして機能します。

個人用AIアシスタントは、承認された文書やファイルを使用できます。添付された参照資料やセッションの承認は範囲を限定しますが、自分の権限を拡大することはありません。モデルやサービスの利用可能性は管理者の設定に依存します。

Chrome / Edge拡張機能をダウンロードするには [ブラウザアシスタント](browser-assistant.ja.md) ウェブページをキャプチャしたり、サイドバーで現在のページを整理したりするため。通常のキャプチャにはモデルは必要ありません。外部のAIクライアントからDocaドキュメントやファイルツールを使用するには、機能を有効にして設定する必要があります。 [MCPサービス](mcp.ja.md) 個人設定において、接続権限や現在のリソース権限は別途チェックされます。

それ [デスクトップクライアント](desktop-client.ja.md) 同じワークスペースをWindowsとmacOSで利用できる：システムブラウザを通じて自分のDocaサービスにログインし、マルチタブワークスペースウィンドウで作業し、複数のサーバーを一度に接続し、次回起動時にウィンドウとタブが復元される。プラグインとデータはサーバー上に保持される。

## アカウントと管理

アカウントページから表示名、アバター、パスワードを変更してください。パスワードを変更すると、そのアカウントのすべてのセッションが終了します。サイト管理者は登録、IDプロバイダ、AIモデル、検索、プラグイン、ウェブホックを設定します。使用する [認証](authentication.ja.md) そして [プラグインデプロイ](plugin-deployment.ja.md) それらのタスクのため。
