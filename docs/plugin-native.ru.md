# Нативная кэш-память плагина и приложения

[中文](plugin-native.zh-CN.md)

В контейнере родного плагина, `host.ai.open` использует `assistant.open` Чтобы открыть встроенного персонального помощника. Параметры и ошибки соответствуют… [контракт запуска](plugin-assistant.ru.md)Призывы и контекст не входят в URL навигации; учетные данные не попадают в WebView. Заполнение запросов происходит в памяти под текущий аккаунт и одноразовый идентификатор запуска.

Публичные типы происходят из `@smartdoca/plugin-sdk/native`, выявленные через `PluginWebHost.native`Эта свойство на сети Web равно null. Контейнер плагина приложения предоставляет:

- `storage.get(key)` / `set(key, value)` / `remove(key)` / `clear()`Строка кэша: максимум 2 миллиона символов на значение и 20 миллионов на плагин.
- `attachments.save({path,name,mime})` / `share(...)`: `path` связано с API плагина, например `/mailboxes/123/attachments/456?download=true`.

Нативный хост связывает пространство имен кэша с сервером, онлайн-проверенным идентификатором пользователя и идентификатором плагина. Плагины не могут выбрать другой идентификатор. Данные хранятся в постоянном каталоге приложения, выживают после перезапуска и удаляются соответствующему серверу при выходе из аккаунта или удалении аккаунта. Записи сериализированы; новый снимок завершается перед заменой предыдущего. WebView остается временным и изолированным; куки входа не являются механизмом постоянного кэша.

Нативный хост проверяет входящее личное лицо онлайн перед загрузкой плагина. Существующий код IndexedDB для плагинов не мигратируется или не применяется автоматически; плагины используют его явно. `native.storage`Полностью оффлайнные запуски не поддерживаются. Удаление приложения или очистка системного хранилища может привести к удалению кэша.

Загрузка приложений осуществляется через внутренний аутентифицированный хост. Перенаправление на внешние источники запрещено, а встроенный токен сессии никогда не передается WebView. Размер приложений не более 32 МБ. Временные файлы удаляются после сохранения или распространения.

Android Save использует системный выбор директории и возвращает `completed` или `canceled`iOS Save and Share показывает таблицу системных разделов и возвращает результат. `presented`Системный API не надежно сообщает о результатах окончательного сохранения/отмены, поэтому `presented` Не достигается успешного сохранения.

Удаление страницы или смена аккаунта отменяет активные нативные запросы. Связывание почтового аккаунта происходит через веб-интерфейс; нет нативного процесса OAuth.

Проверки типов и тесты протокола/скачивания хоста прошли в записанной реализации. Продолжение хранения кэша, использование системы совместного использования и сохранение данных все еще требуют приемки устройств iOS/Android.
