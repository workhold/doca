# 使用指南

[English](user-guide.md)

先閱讀[功能與邊界](features.zh-Hant.md)，瞭解預設部署和獨立外掛的區別。完成[快速開始](quickstart.zh-Hant.md)並登入，即可建立第一篇文件或知識庫。管理員管理站點，資源的所有權和協作授權決定具體內容的訪問許可權。

<a id="文档与知识库"></a>

## 文件與知識庫

透過建立選單新建富文字、Markdown、表格、幻燈片或畫布文件。個人文件是獨立頁面；知識庫提供目錄，可以包含巢狀文件頁面。新文件可使用已註冊模板；[模板與素材](creation-resources.zh-Hant.md)介紹來源選擇和搜尋。

在編輯器中插入圖片和附件。雲端儲存狀態以服務端持久化回執為準；本地副本和未確認更新僅在瀏覽器儲存成功後保留，不能據此承諾完整離線應用或無網路冷啟動。儲存失敗或能力不受支援時，按介面狀態處理。詳見[實時協同](collaboration.zh-Hant.md)。

文件選單按許可權提供分享、複製、移動、歷史和回收站操作。副本有獨立 ID；移動可能改變繼承許可權和公開範圍，操作前檢查目標位置。[文件與分享](document-experience.zh-Hant.md)及[許可權](permission-inheritance.zh-Hant.md)說明具體規則。

<a id="分享与发现"></a>

## 分享與發現

可以設定資源閱讀範圍、邀請具名協作者，或建立分享連結。閱讀、評論、編輯和管理是不同角色。公開知識庫為其中頁面建立閱讀基線。系統管理員不會自動獲得私有內容許可權。

公開發現、個人收錄、收藏和最近訪問有不同用途。訪問不會自動收錄，收錄不會授予訪問許可權，搜尋會重新校驗當前許可權。詳見[發現與收錄](public-resource-discovery.zh-Hant.md)。

## 檔案、評論與通知

窄視窗下，檔案管理的分欄檢視先顯示資料夾內容。選中檔案可預覽，點選關閉按鈕回到資料夾。

普通檔案放在個人檔案或共享資料夾中。下載經過授權，物件 ID 不是公開下載連結。文件可以引用檔案，不需要公開物理儲存目錄。詳見[檔案儲存](storage.zh-Hant.md)。

評論按資源許可權支援回覆、提及、解決和通知。臨時協同游標與永久評論錨點是不同的能力。[評論與通知](comments-and-community.zh-Hant.md)說明可見範圍和當前支援情況。

刪除評論前會顯示氣泡確認。內容評論欄頂部的「已解決的評論」圖示可查詢已解決執行緒及回覆，作者或管理者可恢復為未解決。

<a id="知识整理与-ai"></a>

## 知識整理與 AI

[知識冊](knowledge-books.zh-Hant.md)將明確授權的來源和人工反饋整理為不可直接編輯的 Markdown 文件樹。頁面和個人 AI 助手均可調整編排流程與驗收標準。現有知識庫和訂閱繼續用於來源管理。

個人 AI 助手可以使用已授權的文件與檔案。附加引用和會話審批可以限定範圍，不會擴大你的賬號許可權。模型和服務是否可用取決於管理員配置。

透過[瀏覽器助手](browser-assistant.zh-Hant.md)下載 Chrome / Edge 擴充套件，收錄網頁或在側欄整理當前頁面；普通收錄無需模型。希望在外部 AI 客戶端中使用 Doca 文件與檔案工具時，在個人設定啟用並配置 [MCP 服務](mcp.zh-Hant.md)。兩者的連線授權和當前資源許可權分別校驗。

[桌面客戶端](desktop-client.zh-Hant.md)把同樣的工作空間帶到 Windows 和 macOS：透過系統瀏覽器登入自己的 Doca 服務，在多標籤工作空間視窗中工作，可同時保持多個後端連線，重新開啟時會恢復上次的視窗和標籤。外掛和資料仍在你自己的服務端。

<a id="账号与管理"></a>

## 賬號與管理

在賬號頁修改顯示名、頭像和密碼。修改密碼會退出該賬號的全部會話。站點管理員配置註冊、身份源、AI 模型、搜尋、外掛和 Webhook，相關任務見[身份認證](authentication.zh-Hant.md)与[外掛部署](plugin-deployment.zh-Hant.md)。
