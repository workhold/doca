<a id="conventions"></a>

## Условные обозначения

Пути таблиц имеют `/api/v1` Префикс. Браузеры используют HttpOnly сессионные куки; записи требуют настроенного хоста и той же источника. Нативные клиенты используют Bearer сессии с аутентификацией хоста; WebViews из плагинов используют ограниченные сессии плагинов. Публичные ресурсы раскрывают только свои разрешенные пути чтения.

Метаданные `version`, конфигурация `revision`и содержание `seq`/`epochId` Имеют разные роли. Перед записью прочитайте текущие значения. 409 указывает на конфликт или неподдерживаемый протокол/статус; это никогда не означает разрешение на перезапись. Пагинация зависит от маршрута; следуйте… `nextCursor` или `nextOffset`Отсутствие доступа к контенту, как правило, приводит к возврату кода 404; системное управление не предоставляет доступа к приватному контенту.

## Бухгалтерский учет и администрирование

| Маршрут | Цель и разрешение |
| --- | --- |
| `GET /bootstrap` | Текущий пользователь, сайт, возможности, загруженные плагины; никаких секретов |
| `POST /auth/login`, `POST /auth/logout` | Вход по паролю / выход |
| `POST /auth/register` | Регистрация в соответствии с политикой приема; ожидающие не получают сессии. |
| `GET /me` | Собственный профиль и предпочтения |
| `GET /auth/providers` | Доступные поставщики идентификационных данных |
| `GET /admin/users` | Запрос пользователя-администратора с параметром status/q/cursor |
| `PATCH /admin/users/:id` | `{status:active\|disabled}`Обычный пользователь может включать/выключать; ожидающие действия требуют проверки регистрации |
| `GET /admin/registration-reviews` | Список для проверки администратора |
| `POST /admin/registration-reviews/:id` | `{decision:approved\|rejected,message?}`, специализированный обзор |
| `GET /admin/stats` | Агрегированные статистические данные без разрешения на использование содержимого |
| `GET /admin/users/:id/resource-handover` | Инвентарь ресурсов заблокированного аккаунта; только администраторы |
| `POST /admin/users/:id/resource-handover/preview`, `POST /admin/users/:id/resource-handover/execute` | Предварительный просмотр / подтверждение выбранных прав и привилегий; см. [передача ресурсов](admin-resource-handover.ru.md) |

Проверка контактов, восстановление данных, связь идентификации, проверка безопасности, правила учетной записи и возврат звонков находятся в [аутентификация](authentication.ru.md)Ключи в платформе используются [налаживание сервиса](service-credentials.ru.md); плагины используют отдельный [Сервис шифрованных учетных данных](plugin-credentials.ru.md).

## Поиск

`GET /search/documents` Поиск текущих читаемых документов. Режим ключевых слов может переключиться на базу данных с уведомлением; режим векторов требует наличия Meilisearch и моделей. Результаты перепроверяются на текущем доступе; включение индекса не предоставляет никаких права.

Администрация использует `GET/PUT /admin/search`, `POST /admin/search/reindex`, `POST /admin/search/reconcile`, `/admin/search/embeddings`, `/admin/search/embeddings/status`и `/admin/search/relevance`Результат конфигурации 202 означает, что задача в очереди; завершение запроса. Изменения в модели или квалификациях требуют повторного применения настроек. Политика распознавания изображений в данный момент сохраняет только конфигурацию; её активация не активирует OCR-пайплайн для поиска.

<a id="files-and-storage"></a>

## Файлы и хранение

Используется загрузка активов `POST /assets?purpose=&filename=&resourceId=` с аватаром/обложкой/приложением/изображением комментария и специальным разрешением по цели. Скачивание используется `GET /assets/:id/content`, с `?download=1` Для прикрепления файлов. Изображения аватара/обложки/комментариев могут занимать до 5 МБ; прикрепление документов может занимать до 20 МБ. Файлы обычной платформы используются… `/files` Пути с отдельными ограничениями и многофазные рабочие процессы.

`GET /admin/storage` Сообщает о сервере развёртывания. `PUT /admin/storage` Возвращается 405. Параметры окружения конфигурируют серверы и учетные данные; см. [хранение файлов](storage.ru.md).

<a id="ai-knowledge-and-plugins"></a>

## ИИ, знания и плагины

Сессии и задачи ИИ используют `/ai`Инструменты учитывают объем сессии, реальные разрешения на использование ресурсов и одобрение. `POST /ai/jobs/:id/approval` принимает `{approvalId,approved}` От владельца задачи; одобрение не меняет ACL ресурсов.

`POST /mcp` Раскрывает Streamable HTTP с специальным сервисом Bearer-токен. Личные настройки используются `GET/PUT /me/mcp` и `/me/mcp-services`; интеграция компаний используется `/admin/mcp-services` и должны достичь цели `userId` При каждой операции MCP. Обновление/сброс/отмена сервиса требует текущей версии. Токены отображаются только при создании/сбросе. Смотрите [Настройка MCP, обнаружение инструментов и передача файлов](mcp.ru.md).

Команды Knowledge-Book, процессы работы, человеческие задачи и подписки на источники описаны в [книги знаний](knowledge-books.ru.md)Объединенные источники используются `/content`; см. [протокол содержимого](plugin-content.ru.md)Установлен плагин бизнес-рутин. `/plugins/:pluginId/...` и зависят от загруженного релиза. У хоста нет API для быстрых записок или электронной почты; см. [способности и ограничения](features.ru.md).
