# Публичные ресурсы, открытия и коллекции

[中文](public-resource-discovery.zh-CN.md)

<a id="administrator-policy"></a>

## Политика администратора

В разделе «Права и видимость», «Права на контент», «Публичное обнаружение» администратор отдельно устанавливает документы, библиотеки и папки:

| Режим | Каталог открытий | Поиск полного текста перед сбором | Личный поиск после сбора |
| --- | --- | --- | --- |
| Ссылка только | Скрытое | Исключено | Включено |
| Можно обнаружить, можно искать после сбора | Показано, запрос по названию | Исключено | Включено |
| Сайт, который можно обнаружить и поискать на всей площадке | Показано, запрос по названию | Включено | Включено |

Политика изменяет только способ распределения ресурсов, которые уже являются публичными. Она не публикует какие-либо приватные ресурсы. Если все три типа ресурсов представлены только в виде ссылок, остаются публичная запись, вкладки «Посещенные» и «Собранные», а вкладка «Откройте» скрыта. API не возвращает ресурсы, которые не могут быть обнаружены.

До того как новая политика будет сохранена, более старые настройки распространения сохраняют свое предыдущее значение. Сохранение записывает три независимых параметра. `publicModes`История посещений сохраняется.

<a id="personal-scope"></a>

## Личный объем

Посещение ведет запись посещения, но не собирает ресурс. Старый автоматический `source=opened` Ряды не подходят для поиска в коллекции и не отображаются в списке коллекции. Прямые гранты, принятые приглашения и право собственности все еще подчиняются своим правилам.

Все три типа ресурсов используются `resource_collections`Уникальный для пользователя, тип ресурса и идентификатор ресурса. Публичный каталог не скрывает публичные ресурсы, которые вы владеете или можете получить доступ к ним. При добавлении ресурса он добавляется в список. Он не фильтруется по предыдущему разрешению.

Поиск кандидатов представляет собой сочетание предыдущего диапазона, любимых объектов и списка коллекций. Результаты снова проверяются с учетом текущего доступа. Удаление коллекции уничтожает только строку в этом списке; это не влияет на членство или приглашения. Ресурс, который уже был доступен для поиска, остается доступным для поиска.

Текущая схема создает пустую таблицу коллекции; при запуске исторические записи не копируются в нее. Существующие строки коллекции остаются нетронутыми. Автоматические соединения, приглашения или записи посещений не рассматриваются как коллекции.

Поиск может использоваться для поиска во всем, что можно найти, в пределах моего диапазона и в общем тексте сайта. Общий текст сайта включает только ресурсы, которые администратор разрешил для поиска на уровне всего сайта. Поиск по заголовкам в каталоге обнаружения не включает поиск содержимого или векторного поиска. Поиск файлов и поиск файлов с помощью ИИ также проверяют коллекцию контейнеров и политики общей поиска.

<a id="containers"></a>

## Контейнеры

Сбор библиотеки или папки включает как существующий контент, так и контент, добавленный позже. Способ запроса делает это динамически. Не копируется строка членства в каждый ребенок.

Публичная библиотека определяет область чтения страниц. Страница, которая отключает наследование для коллабораторов, все равно может позволять публичное чтение. Страница все еще может настроить функции редактирования, комментирования и управления правами. Поиск по точкам и списки в SQL используют ту же политику публичного чтения. Страница, находящаяся внутри библиотеки, подчиняется политике обнаружения и поиска библиотеки. Самостоятельный документ подчиняется политике документа.

Файл публикации хранится в `folder_publications`Пользователи с активной аутентификацией могут читать текущий и будущий контент. Они не получают управление. Управление файлами и скачивание в настоящее время требуют входа. Нет возможности доступа к файлам без анонимности. После отключения публикации доступ определяется в зависимости от текущего членства. Сама коллекция не предоставляет доступа.

Панель разрешений страницы показывает публичную библиотеку в качестве источника. Панель разделения папок указывает, что публичный объем включает текущий и будущий контент. Перемещение в публичный контейнер публикуется вместе с контейнером. Перемещение в другое место использует новое местоположение.

<a id="discovery-ui"></a>

## UI для открытия обнаружений

На странице публичных ресурсов есть функции «Посетил», «Откройл» и «Собрал», фильтруемые по документам, библиотекам и папкам. «Посетил» включает публичные ресурсы, содержащие только ссылки, которые пользователь открыл и может продолжать использовать. История посещений не обеспечивает право на поиск. В списке бизнес-ресурсов больше нет скролл-кнопки для доступа к публичным ресурсам.

Дома `/home` сводит краткие сведения о недавних посещениях документов, библиотек, папок и файлов, а также о ожидающих заявках и решениях библиотеки. Документы были перемещены `/documents` И сохранять недавние посещения, принадлежащие мне, совместную работу, любимые элементы и мои коллекции. Диалект «Все» для библиотек объединяет владение, совместную работу, любимые элементы и коллекции. Он не автоматически отображает публичный каталог всей страницы. Общие папки не имеют любимых элементов. Они предлагают все: общие со мной, общие со мной и собранные.

Общественные списки предоставляют функции сбора и отмены сбора. В меню документа также есть опции сбора, отмены сбора и удаления, при которых пользователь может удалить документ. Любимые и закрепленные элементы остаются в виде скорочтений. На странице деталей ресурса не добавляется ещё одно поле для сбора.

Главная статистика использует данные, к которым имеет доступ текущий пользователь. Тикеты повторно используют процедуры одобрения и приема, принадлежащие только одному человеку. Решения в библиотеке повторно используют разрешение на обслуживание и ожидающую калибровку. После обработки они покидают дом. Падение источника отображается отдельно и не представлено как нулевое количество ожидающих задач. Первая версия использует встроенные источники. Еще нет внешнего плагина для дома SDK.

Документы и библиотеки используются `resource_visits`Файлы и папки используются `workspace_activity`Недавние посещения снова разрешены, затем они объединяются и отсчитываются по времени. Открытие предварительного просмотра файла считается посещением. Список изображений-миниатюр не считается посещением.

Первая фаза включает запросы по названиям, порядок по времени обновления, стабильную навигацию по страницам, сбор данных и обработку групп данных. Библиотека представлена в виде контейнера; её страницы не сгруппированы в список. Запросы осуществляются с использованием каталога базы данных. Не требуется новых зависимостей от Meilisearch, а также не предусмотрен рекомендательный фид.
