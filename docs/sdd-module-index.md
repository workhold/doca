# SDD module index

[中文](sdd-module-index.zh-CN.md) · [Workflow](sdd.md)

This index connects existing modules to source, current contracts and reusable checks. It does not certify existing functionality or rerun historical acceptance. Check actual exports and lockfile versions before work; consult the [architecture](architecture.md) and applicable release notes for current limits. Add a new SDD when changing a module, and update its authoritative contract in the same PR.

Test links are entry points, not a sufficient test plan for every change. Pick checks against the acceptance criteria and real boundary: SQLite results alone do not prove PostgreSQL upgrades; mocks do not prove external providers; local tests do not prove native devices or production deployment. Read applicable skills before changing those domains. Existing independently versioned editor packages and business plugins need their own repository checks and explicit integration-version records.
