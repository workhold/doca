# Обслуживание документации

[中文](documentation.zh-CN.md)

Документация использует Docsify 5.0.0. Источник на Markdown остается `docs/`; `docs/site/navigation.json` Определяет публичные страницы и их порядок просмотра. Пути источников технического контракта остаются стабильными для репозитория и ссылок на редакторские навыки.

## Макет

| Группа | Контент |
| --- | --- |
| Начало работы | Быстрое начало, настройка, руководство пользователя, решение проблем |
| Руководства для пользователей | Документы, обмен, права доступа, заметки, знания |
| Развертывание и эксплуатация | Docker, хранение данных, масштабирование, аутентификация, ключи сервисов, вебхуки |
| Разработка | Настройка источника, архитектура, редакторы, совместная работа, языки интерфейса |
| Плагины | Разработка, установка, общественные услуги, взносы |
| Ссылка | API, база данных, SDK и контракты редактора |
| Выпуск | Изменения, требования и проверка, связанные с версией |
| Проект | Обслуживание документации и записи о первичных исследованиях/приеме |

Текущие публичные страницы имеют восемь языковых версий. Основным источником является `name.md`Последовательности языка, пути и тексты навигации определены в `docs/site/languages.json`Релизы до версии 0.3.0, записи о исследованиях и утверждениях сохраняют свои оригинальные версии и область проверки. На верхней части исходных файлов указываются устаревшие реализации и замененные предложения. В списке реализаций отдельно указаны экспортируемые API, предложения и не проверенное поведение внешних сервисов/устройств.

Новые изменения следуют за [Система ранжированного процесса SDD](sdd.ru.md). The [модуль индекс](sdd-module-index.ru.md) Связывает источник, авторитетные контракты и повторно используемые проверки. Спецификации описывают отдельные изменения; текущие технические контракты сохраняют свои существующие пути источников, и обновляются в том же PR при изменении поведения.

## Проверить и просмотреть предварительно

```sh
pnpm install --frozen-lockfile
pnpm docs:check
pnpm docs:dev
```

Открыть `http://127.0.0.1:39140/#/en/` или `http://127.0.0.1:39140/#/zh-cn/`Предпросмотр предназначен только для просмотра документации; он не запускает Doca и не подключается к его базам данных. Перезапустите команду после изменений исходного кода, чтобы снова создать директорию публикации.

`pnpm docs:build` готовит `.cache/docs-site/` с папками, такими как `en/getting-started/` и `zh-cn/operations/`Он копирует и переписывает ссылки в формате Markdown; Docsify отображает контент в браузере. Он не компилирует код приложения и не генерирует Markdown-текст в HTML. Сгенерированный каталог игнорируется Git.

Ссылки на официальные страницы остаются в текущем языке. Ссылки на языки показывают соответствующую страницу, когда та версия доступна. Ссылки на исходный код, примеры и исследования открывают соответствующие файлы на GitHub. Страницы имеют ссылку на исходный код и ссылки на доступные версии. Несуществующий перевод не проходит проверку, и не используется другой язык в качестве замены.

`docs:check` инвентарные записи в Markdown через Git, включая неучтенные новые файлы и исключение `tests/fixtures/`Он проверяет ссылки в формате Markdown/HTML и целевые элементы заголовков во всей документации репозитория, включая ссылки на основную ветку этого репозитория. Не обрабатываются артефакты и внешние URL с датой или метками. Опубликованные анкоры заголовков дополнительно проверяются согласно правилам Docsify. Проверка также сравнивает текущие входы в релизы, матрицы пакетов редактора, все строки таблиц/полей базы данных (включая наследованные интерфейсы Схемы) и пять справочников по навыкам, адаптируемых к переносу, с соответствующими документами источника. Типы TypeScript читаются без открытия приложения базы данных. Наличие внешних веб-сайтов и семантическая корректность каждого утверждения все еще требуют проверки.

Бегать `pnpm test:docs` Для случаев регрессии проверки. После редактирования контракта выполните запуск. `node scripts/sync-docs-skills.mjs`Он сохраняет исходный текст и переписывает относительные ссылки для использования вне процесса оплаты. Опциональный аргумент директории installed-skills также обновляет установленные ссылки. Например: `node scripts/sync-docs-skills.mjs /absolute/path/to/installed/skills`Сохраняйте любые установленные копии синхронизированными в соответствии с правилами обслуживания соответствующих навыков.

Это `.github/workflows/docs.yml` В рамках workflow проверяется документация в pull-запросах и публикуются изменения `main`Настройте репозиторий под **Настройки → Страницы → Сборка и развертывание → Источник → GitHub Actions**Рабочий процесс использует `github-pages` Среда развертывания и правила её утверждения. Предполагаемые входы:

Подавайте содержимое `.cache/docs-site/` для публикации в других местах. Хеш-маршрутизация поддерживает подпуть репозитория и прямые обновления без изменения маршрутов сервера. Сгенерированное… `.nojekyll` Сохраняет файлы навигации, отмеченные курсором, при размещении через Pages.

## Активы и обновления

Проанализированы резюме проверок, а приложения к документам хранятся. [`docs/verification/`](verification/README.md)группированные по случаю принятия или выпуска. Повторно используемые входные данные скрипта относятся к `tests/fixtures/`Сгенерированные логи, снимки экрана, отчеты и кэш сохраняются. `artifacts/`Это полностью игнорируется Gitом; для сохранения новых доказательств не требуется изменений в правилах игнорирования.

Рунтрейнт Docsify, плагин по поиску, стили светлый/темный и лицензия MIT продаются в комплекте `docs/site/assets/vendor/docsify/`. `README.txt` Записывается версия и проверяется целостность tarballа npm из upstream-источника. Эти ресурсы загружаются с сайта документации. Диаграммы Mermaid загружают пингодованную версию Mermaid ESM постепенно. `site.js`Им необходим доступ к этому CDN.

При добавлении публичной страницы создать все восемь версий, добавить страницу к `navigation.json`и запустить `pnpm docs:check` и `pnpm docs:build`Привяжите непубличный технический/дизайнерский запись. [исследования](research.ru.md)и обзорный отчет о проверке от [индекс проверки](verification/README.md). Соблюдайте согласованность примеров кода и требований к версиям. При обновлении контракта следуйте соответствующим правилам репозитория и обновляйте упомянутые в контракте ссылки по необходимости. Ассеты во время выполнения и дополнительные плагины требуют явного выбора версии и проверки в браузере.

Четвертое значение в записи навигации релиза — `true` Когда будет доступно все восемь языковых версий. Сохраняйте этот статус после выпуска последующей версии. Поместите проверенные снимки экрана в поддиректорию языка. `docs/images/` Таким образом, сайт и файл README могут ссылаться на соответствующий интерфейс.
