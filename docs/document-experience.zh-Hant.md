# 文件、分享與歷史

[English](document-experience.md)

本文描述宿主 0.2.23 原始碼；早期開發與臨時包記錄歸入[研發資料](research.zh-Hant.md)。

<a id="创建与编辑"></a>

## 建立與編輯

建立選單提供富文字、Markdown、表格、幻燈片和畫布，五種格式均已接入編輯器和獨立協同編碼。模板需要已安裝的提供者，預設仍可建立空白文件。個人文件為獨立頁面；知識庫文件按庫目錄導航。

圖片與附件走宿主上傳、資產 ID 和授權下載。編輯需要 editor 或更高許可權，儲存以資料庫提交後的回執為準。瀏覽器儲存成功時，原始 checkpoint 與未確認更新會持久儲存在 IndexedDB。重開仍需可用的本地副本和應用靜態資源，詳見[離線限制與恢復](collaboration.zh-Hant.md#保存、重连与历史)，並留意儲存失敗提示。工具、查詢替換、線上選區與評論因格式而異，見[編輯器整合](editor-integration.zh-Hant.md)。

當前離線工作臺原始碼在桌面版和已下載前端的瀏覽器中提供**賬號選單 → 離線文件**。後端不可達時，此目錄也會出現在工作臺首頁。開啟副本時，編輯許可權依據最後一次校驗結果，伺服器恢復後會重新校驗並同步。見[啟用離線文件](access-offline-events.md#离线文档入口)。

文件頁的最近訪問列表可以滾到底部，列表篩選停靠在上方。知識庫和離線文件目錄在內容超出視窗時也可以滾到最後一項。

<a id="分享与权限"></a>

## 分享與許可權

分享面板管理閱讀範圍、邀請、成員授權來源和連結。變更檢查版本或修訂號；409 衝突需要重新整理後重新操作。管理許可權及所有權操作受各自授權規則約束，見[許可權](permission-inheritance.zh-Hant.md)。

連結使用 `#/s/{token}`，登入後預覽和接受。連結總開關、具體連結停用/過期、成員來源撤銷是不同操作；撤銷某一來源不影響其他有效來源。公開閱讀、發現、收錄和收藏分別處理；收錄不授予訪問權，系統管理員也不會自動取得私有正文許可權。

<a id="历史与恢复"></a>

## 歷史與恢復

- 文件選單提供歷史列表、快照預覽和手動快照。歷史讀取預設需要編輯許可權；開啟閱讀者歷史許可權後，可按資源閱讀權檢視。
- 近期恢復點保持密集，長期歷史每十個舊快照保留一個。使用者使用同一個快照列表與預覽/恢復操作，不需要關注儲存位置。其餘九個點按規則抽稀，見[儲存運維](storage.zh-Hant.md#历史快照存储与显式升级)。
- 富文字和 Markdown 的可恢復快照提供恢復操作，需要 manager 或 owner。提交 `expectedSeq` 校驗當前正文；衝突後重新讀取，避免舊預覽覆蓋新編輯。
- 表格、幻燈片、畫布已有快照及只讀預覽，當前返回 `canRestore: false`，沒有恢復按鈕。
- 業務歷史與協同 checkpoint 分別持久化。恢復依賴快照自身的格式、譜系及資產，不用當前正文冒充缺失歷史。
- 訪問與操作記錄按當前許可權讀取，不是正文備份，也不能補出過去未儲存的快照。

<a id="移动、复制与回收站"></a>
<a id="移动复制与回收站"></a>

## 移動、複製與回收站

移動前檢查目標和子文件許可權，並確認授權重置的影響。所有權轉移僅由所有者執行。複製建立獨立資源及正文身份、重新繫結資產，不復制授權、評論或撤銷歷史。刪除進入回收站；恢復遵循刪除批次和父級狀態。永久刪除走明確的清理操作及許可權檢查，不等於刪除所有共享儲存物件。

<a id="接口与源码"></a>

## 介面與原始碼

路徑以 `/api/v1` 為字首：

| 介面 | 用途 |
| --- | --- |
| `GET /resources/:id/versions` | 歷史列表 |
| `POST /resources/:id/versions` | 手動快照 |
| `GET /resources/:id/versions/:versionId` | 預覽及當前正文序號 |
| `POST /resources/:id/versions/:versionId/restore` | `{expectedSeq}`，恢復支援的格式 |
| `POST /share/redeem` | `{token, accept?, consume?}`，預覽/接受連結 |
| `GET /resources/:id/info` | 統計、訪問或操作記錄 |

實現見 [experience.ts](../apps/server/src/routes/experience.ts)、[歷史服務](../packages/core/src/modules/history/service.ts)和[編輯器分派](../apps/web/src/features/documents/document-editor.tsx)。完整部署介面以 `/api/openapi.json` 和服務端校驗為準。
